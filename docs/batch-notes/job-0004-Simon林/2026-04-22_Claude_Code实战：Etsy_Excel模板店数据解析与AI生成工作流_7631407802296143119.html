Claude Code实战：Etsy Excel模板店数据解析与AI生成工作流

一、内容简述

（一）一句话结论

一句话结论 本文基于Etsy上两家头部Excel模板店的真实销售数据（销量14.7万和15.3万单），分析了零库存、低边际成本的商业模式。详细阐述了利用Claude Code通过命令行、Excel插件及MCP三种路径生成Excel模板的方法，并提供了通用的提示词框架和反向工程（逆向分析竞品）的操作建议，旨在为读者提供可落地的AI商业应用案例。

（二）核心内容

  1. Etsy Excel模板店商业案例数据
    分享了两家Etsy头部Excel模板店的真实数据：一家拥有48款SKU，3年销量14.7万单，客单价约7-8美元，中位数估算收入约17万美元；另一家拥有225个SKU，销量15.3万单，评价超1万个。案例展示了该赛道需求巨大，无论是做超级精品还是铺货模式均可行，具有零库存、零物流、零边际成本的优势。

  2. AI生成Excel模板的三种技术路径
    介绍了使用Claude Code制作Excel模板的三种方式：1. 命令行模式：通过自然语言指令让Claude Code编写Python脚本（使用openpyxl库）操作Excel；2. Excel内嵌插件：使用Claude Code或ChatGPT的Excel插件直接生成；3. MCP模式：通过MCP协议连接Claude Code与Excel。其中命令行模式需安装openpyxl等库，可通过截图指令让AI辅助安装。

  3. 通用提示词与反向工程方法论
    提供了一套Etsy级别的通用提示词框架，涵盖视觉风格、页面结构、功能要求和交付动作。建议采用反向操作：先研究竞品店铺的产品介绍，将资料喂给AI，让AI生成生产此类产品的提示词或直接生成模板。产出速度快，约10分钟可出一个版本。

  4. 模板结构与运营建议
    生成的Excel模板应包含多个系统（如Dashboard前台、收入、支出、月度Overview等），不能仅有一个简单表格。可通过微调配色、结构和公式达到类似Shopify或Etsy上成熟产品的水平。核心在于平台的销售与运营，该模式已验证可落地，适合借鉴运作。
