1. 问题引入

听说你是瘦子，想增重，但是肠胃吸收不好怎么办？还有救吗？

2. 训练必要性

当然有救，你不能只知道吃，你还得去健身房训练。如果你不训练，不刺激身体，身体不需要更多的营养，吃进去的东西当然就不吸收。

3. 增重原理

如果你有做负重训练，肌肉受到充分的刺激之后，肌肉是要恢复生长的嘛。这个时候呢身体就需要更多的营养，我们吃进去的东西就被吸收了，人就变壮了。所以这个本质上不是肠胃吸不吸收的问题，而是身体需不需要的问题。

4. 亲身经历

我的肠胃也很差，以前怎么吃都吃不胖，喝了两年的中药调理肠胃也没什么效果，因为身体不需要。后来我开始健身训练，刺激肌肉，身体有需要了，吃进去的营养也吸收了。我现在也比以前增重了整整五十斤。
