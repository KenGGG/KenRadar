（一）一句话结论

一句话结论 本集教程演示如何利用Claude Code（CC）自动化拉取特定行业的研报，以填充之前搭建的大A投研看板框架。核心技巧包括通过修改API参数（qtype=1）批量获取行业研报而非个股研报，并结合i问财接口提高效率。随后使用高性能模型阅读研报，提取环节定位、技术/产能壁垒及竞争格局等关键信息填入框架。强调使用聪明模型以保证分析质量，并指出该方法论可复用于AI算。

（二）核心内容

  1. 核心目标与数据源策略 本期目标是利用Claude Code拉取研报以填充投研看板。策略上优先拉取行业级研报而非个别标的，因为行业研报经过机构认证，具有参考价值且适合批量处理。

  2. API调用关键技术细节 通过向Claude Code发送特定指令调用Astock Data接口。关键参数是将qtype从默认的0（个股）设置为1（行业）。建议要求每个子行业拉取不少于300份研报，或指定时间范围（如2026年最新数据），且不传入具体标的代码。

  3. 辅助工具与数据处理 建议结合i问财接口一起使用以提高效率和数据量。拉取的研报需进行归类整理至研报库。

  4. 研报分析与框架填充 使用高性能（聪明）模型阅读大量研报，避免使用低效模型导致结论偏差。重点提取环节定位、壁垒类型（科技或产能）、国内外竞争格局等信息，填入投研框架。

  5. 方法论推广与总结 该流程适用于人型机器人、AI算力等多个赛道。强调使用高成本、高智能模型以确保壁垒分析和性能格局分析的准确性。系列教程暂告一段落，用户可根据需求自行扩展功能。
