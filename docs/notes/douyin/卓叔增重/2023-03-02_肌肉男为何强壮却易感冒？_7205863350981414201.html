（一）一句话结论

一句话结论 高强度健身会导致短期免疫力下降（免疫窗口期），主要因血糖和谷氨酰胺降低、皮质醇升高所致。部分健身者因训练后肌肉充血穿背心外出受凉感冒，实为自身防护不当所致，建议练后及时擦干汗水并添衣保暖。

（二）核心内容

  1. 健身与免疫力的关系 健身并不能明显提升免疫力，甚至可能暂时降低。高强度持续运动会导致血糖和血液谷氨酰胺浓度下降，免疫细胞缺乏营养，免疫功能受抑制。

  2. 免疫窗口期的成因与周期 高强度训练会引起皮质醇过量积累，损伤免疫T细胞并分解抗体蛋白，导致免疫力低下。此现象称为免疫窗口期，通常出现在剧烈运动后的72小时内。

  3. 免疫力恢复与健身者行为误区 免疫力轻微下降通常问题不大，充分休息和营养补充后可恢复正常甚至超量恢复。但部分健身者训练后肌肉充血，为展示身材穿背心外出，易受风寒感冒。

  4. 感冒原因分析与防护建议 肌肉男感冒并非肌肉本身有问题，多因训练后未及时擦干汗水、未做好保暖导致受凉。建议健身达人在练后及时擦干汗水、穿好衣物，避免着凉。

1. 健身对免疫力的影响

健身的人，特别是那些肌肉男，为什么总是容易感冒生病呢？因为生病是身体免疫力的问题。但健身并不能明显提升免疫力，甚至有时候会降低免疫力。高强度健身之后会有一小段时间被称之为免疫窗口。因为大量的持续性运动会，让血糖水平和血液中的谷氨酰胺的浓度明显下降。这些其实都是免疫细胞的粮食，含量不足了，免疫功能就会稍微受到一些抑制。

2. 免疫窗口期的生理机制

而高强度的训练还会造成皮质醇的过量积累，皮质醇会伤害免疫T细胞，并且分解抗体蛋白，导致最终一段时间内的免疫力低下。免疫窗口期就是这么来的，一般会出现在剧烈运动后的七十二小时内。一般来说吧，免疫力稍微下降一点，其实问题不大，大家吃好穿好，休息好，一般很快就恢复成原来的样子了嘛，甚至会超量恢复，免疫力越来越好。

3. 健身者行为与感冒诱因

但是那些健身练出一点成果的人吧，都有一个毛病啊，比较自恋啊，不说高情商，一点都比较喜欢展示自身的魅力，就是那种鼓胀的胸肌。所以他们刚练完肌肉，肌肉充血，比平时看的大一圈，机会难得，穿个背心就走出健身房了，使劲享受路人的目光哦。然后风一吹，喷嚏一打就着凉感冒了呗，这不就是活该吗？

4. 防护建议

肌肉男感冒并不是肌肉有什么问题，基本都是自己惹出来的。所以这里建议各位健身达人们练完之后好好的把汗擦干，把衣服穿好，不要着凉。
