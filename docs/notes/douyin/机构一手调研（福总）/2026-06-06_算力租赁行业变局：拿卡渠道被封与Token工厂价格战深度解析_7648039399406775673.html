一、内容简述

（一）一句话结论

一句话结论 本文深入解读算力租赁行业近期两大核心变化：一是美国商务部5月31日发布执行指南，彻底封堵中资企业通过海外子公司获取高端算力芯片（如B200/B300）的渠道，导致供应链紧张及国产替代加速；二是国内大模型厂商掀起惨烈价格战，Token单价大幅下跌，旨在争夺用户生态和数据壁垒。文章分析了行业分化格局、Token分成商业模式的早期特征及短期投资风险，指出尽管价格战。

（二）核心内容

  1. 美国新规封堵海外拿卡渠道 美国商务部于5月31日发布执行指南，实施穿透式监管，要求所有中资背景实体（包括在新加坡、中东等地设立的海外子公司）采购先进算力芯片均需获得美国商务部BIS出口许可证。此举彻底封死了此前通过离岸市场部署算力并中转至国内的合规漏洞，导致中资企业获取高端芯片路径受阻80%-90%，英伟达芯片价格跳涨，卖方市场特征明显。

  2. 算力租赁行业格局分化 行业呈现强者恒强态势。第一类拥有存量资源和长期合同的头部厂商营收确定性高；第二类在涨价前完成采购储备的厂商成本优势凸显；第三类新进入者面临供货难、成本高及违约风险，生存空间被压缩。头部企业倾向于使用国产GPU以保障供应链安全。

  3. Token工厂价格战与生态争夺 国内大模型厂商（如DeepSeek、小米、腾讯云等）展开极致价格战，Token价格降幅高达97%-99%。这并非单纯亏损，而是为了争夺用户生态、数据和场景习惯，类似于当年的网约车大战。降价释放了需求，增加了算力消耗，利好上游算力租赁和Token分成商。

  4. 商业模式转型与投资逻辑 算力租赁厂商正从“裸算力出租”向“Token计费服务”转型，以提升估值和运维效率。Token分成模式目前处于早期阶段，主要依靠补充协议签约，行业标准未定，短期多为概念炒作，长期价值取决于大模型使用量和收入规模的显著提升。国内变现最快的是AI视频领域。

1. 引言与市场背景

短短一个礼拜，市场好像要变天，算力租赁行业已经变天。从上周末到现在，算力租赁行业迎来了几条足够改变行业现状和预期的关键事件，由美国的封堵，还有暴跌式的价格战。不光有美国对算力租赁大厂海外最后一块拿卡渠道，打上合规的补丁，还有Token算力超过腰斩，甚至是脚踝斩的价格战。那么今天我们就结合机构最新的专家交流会议和我们在黄牛渠道了解到的行业现状，以及模型厂对Token价格的趋势展望，来给大家对算力租赁这个行业一周发生的惊天动地的变化，做一个客观、详细、深度的解读。

2. 美国商务部新规详解

首先，五月三十一号，美国商务部发布了一则看似简短但却威力巨大的执行指南，让整个AI智算的投资圈、黄牛渠道，甚至是互联网大厂和算力租赁公司炸开了锅，因为彻底击碎了过去这大半年时间里，国内算力圈心照不宣，闷声发财的最后退路。那就是通过设立海外子公司在离岸市场部署先进算力的路径。事件的起因呢是二五年的五月份，美国的商务部曾宣布暂缓执行复杂的全球化AI扩散规则，也就是川子的政府不再执行拜登政府时期对我们实行的小院高墙全面围堵的一个策略。那么这就带来了部分的市场主体，利用海外合规节点的漏洞，采用了曲线救国的办法。在新加坡、马来、印尼、泰国、中东甚至欧洲，设立海外的独立法人，甚至联合海外的本地财团，在当地建立AIDC计算中心，并采购英伟达的高端服务器，如B200、B300，有一些留在了海外，为海内的大模型在海外的数据中心提供更复杂的训练任务。还有很大一部分是通过这些第三国进行中转，最后采用合法报关的方式引进到了国内。毕竟是美国不允许出口到大陆，但是大陆并没有禁止进口，但是五月三十一日的文件给了这个漏洞致命一击。直接来了穿透式监管，全域无死角。哪怕你的子公司开在新加坡，只要他的背后大老板是中资企业，那么也必须要获得美国商务部BIS的出口许可证才可以采购，而且还要老账重算。商务局澄清，虽然二五年AI扩散规则暂缓，但是二三年十一月十七日确立针对中资背景实体的重点控制，老规矩，从未停止执行。所以，所有试图用海外马甲续命先进算力的这些通道，在美国的最新法律和合规层面已经被彻底封死。限制的对象，从原来的中国境内企业使用方扩大到了股权可追溯至中资的所有主体。而且，即便主体注册在新加坡、马来、中东、港澳地区也同样被纳入受限范围，而且限制的范围覆盖了B系列以及Rubin系列所有芯片。那么根据机构调研了解到的情况，目前美国的商务部已经在全球设立了十一位监察专员，而且在新加坡地区的专员在政策发布之前就已经开始行动。所以这一次政策的落地有美方的系统联动支持，而非临时性的举措。

3. 新规影响与供应链反应

那么这个影响将会延伸到算力供应商、供货商以及终端客户的全链条。那么新规出台后，短短的这五天不到的时间，英伟达全系列的算力芯片都得到了一个跳涨，甚至B300的服务器从周末的七百四十万已经来到了当下的八百万以上，而且正在部署AIDC，甚至是算力租赁的这些企业，上游的供货已经出现明显的障碍，未来拿卡的增量受限情况将非常明显，高端芯片从原先的供不应求，进一步转向卖方市场。所以有了大家看到的一千万报价都能被喊出来。那么新规出台之后看到了当前的变化，我们同时也能预感到未来的趋势。即使在短期的一两个月内执行的情况有松口，那么你如果是互联网大厂或者是算力租赁的采购厂商，你会愿意自己的整条业务生命线都被美国的BIS商务部拿捏在手里面吗？所以头部的终端客户已经开始考虑用国产GPU代替英伟达来保障供应链的安全。虽然大家都知道英伟达卡好，但是已有的算力被迁出去了，现有的算力我拿不到，或者是这种千万天价的算力，我拿到了你承担不承担得起，那么也能预计后面算力租赁商的业务布局也将会跟随终端客户的需求决策去做出调整和选择。

4. H200库存与国产替代

说到这儿，我们在和业内的人士去做调研和交流的时候，他们也聊到了一个比较凑巧的事情。这个只代表行业内部分人士自己的观点和判断。那么就是此前总共十单合计七十五万颗的H200芯片在会面的时候，是已经获得了美方商务部的审批的。那么审批之后，流程要回到国内的商务部和工信部，大概需要一个月的时间进行批复。那么假如美方是誓死封杀时机，彻底封死了高端的B200、B300，甚至是下一代的Rubin。那么他们想卖给我们的这七十五万片的H200库存，就成为了当下合规渠道里面唯一能规模拿到的英伟达卡。所以他们认为这有没有可能是在给我们上压力。所以接下来的这十几天的窗口，我们关注国内的回应非常重要。但无论这件事情的结果如何，我们在双方AI领域竞争的最高地，也就是算力芯片领域，都是在互相卡脖子。我们刚发布淘金率，引导未来半导体行业自主可控的发展，那边就发布了史上最严的BIS禁令，全面封杀特殊渠道。英伟达显卡贸易以国产算力这条路，我们仍然会坚定不移的走下去。哪怕现在没那么好用，但至少不会因为别人的一纸文件就全军覆没。

5. 算力租赁行业竞争格局变化

那么这件情按目前前状发展展去对算力租赁行业竞争格局会带来什么样的变化呢？行业会分化，市场像存量资源已锁定长期订单的头部厂商集中，但是新进进入者的门槛又大幅提升了。第一类是前已经搭建完成大量算力资源池，并且已经拿到长期订单的头部企业。也就是我们说的这些强者恒强，毕竟他们们的存量合同不受影响，营收的确定性还是比较高的。因为头部的这些算力租赁公司签的都是三加二的合同，前三年是闭口合同，价格不变，后两年再根据市场到时的情况进行重新议价。那么按照目前的算力租赁价格基本上是前三年就能够收回成本，而且还有余，那么剩下的两年就是绰绰有余了。而且已搭建完成，但尚未进行订单锁定的可释放资源，接下来也会用涨价的方式来传导市场，整体成本水位的飙升，那么收益率会进一步的提升，但是这是行业层面。投资层面，大家要注意到这个隐秘，但又被市场投资者熟知于心的核心能力。也就是拿卡渠道是说我们开头警示的影响的。所以未来的利润会释放，但是利润进一步的上调的空间要打一个问号。那么第二类厂商就是已经采购到芯片或者是服务器，但没有完成搭建的厂商，那么在手的资源将变得更加紧俏。如果是在设备涨价前已经完成采购和储备的，那么算力服务器只占了算力资源池的百分之七十的成本得到了有效的控制。剩下百分之三十的交换机、光模块、组网、运维、机房、电费，这些更是不会受到短期价和波动的影响，所以成本优势会体现出来，收益的弹性也会有所上调。那么第三类厂商就是这些在四月份以后大张旗鼓跃跃欲试，开始准备新切入算力租赁的公司，也就是我们所说的那些蹭概念的公司。那么这些公司虽然刚拿到了银行的授信，股东批准了预算，但是在新规出台前并没有采购到设备，这问题就来了。现在上游供货的难度大幅提升，哪怕你是像之前一样继续找这些国内的NCP渠道支付溢价来采购。那么现在NCP渠道自己手里面的货都不够用了，那么卖给你的得涨多少呢？你还敢不敢继续做呢？做了的话，你能不能找到这样高价的订单呢？那么还有一些喜欢炒股的公司还没拿到设备，没有组网呢，先签了意向订单。那么接下来他们将面临无法交付的违约风险。那么这些新切入的玩家，有可能一口汤都没喝上，还要支付一笔数额不小的违约金。当然有可能他们在自己公司的股价里面已经赚到这个钱了，最后的损失可能是股民来买单。所以我们前面视频的标题强者恒强，弱者消失，在面临这样的行业巨变面前又被验证了。

6. 算力需求端与价格趋势分析
