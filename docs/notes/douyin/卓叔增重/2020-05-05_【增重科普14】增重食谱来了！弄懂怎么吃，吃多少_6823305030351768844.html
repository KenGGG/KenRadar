1. 早餐安排与重要性

瘦子要怎么安排？一日六餐。第一顿是早餐，可以安排肉包子两到三个、白煮蛋两到三个、坚果一小把，还可以吃一点水果。早餐是全天最重要的一顿，必须吃好吃够。如果不吃早餐，增重基本是没有希望的。

2. 午晚餐与主食搭配

第二、第三顿是午餐和晚餐，至少要有两份以肉类为主的主菜，补充足够的蛋白质。再吃两到三碗白米饭，补充足够的碳水化合物。蔬菜自己看情况添加。

3. 加餐时间与食物选择

第四到第六顿是加餐。可以在早上十点、下午三点或晚上二十一点，至少选择两个时段安排加餐。加餐可以准备一根香蕉、两片面包、一盒牛奶就够了。

4. 进食困难应对与训练后补充

有的人觉得太多了，吃不下怎么办？可以先从吃一根香蕉开始，等你适应了，下次再加一片面包。训练完之后还可以喝一杯增肌粉，迅速补充大量蛋白质和碳水。这就是瘦子增重每天要吃的内容，有点多，习惯了就好。

5. 体重监测方法与下期预告

怎么样才能知道自己吃得够不够呢？每周一早上空腹称一次体重。如果体重比上周上升了，说明吃够了；如果体重没有变化，说明没吃够，要继续加量。下一集我会讲瘦子增重，每天都训练效果会不会更好？
