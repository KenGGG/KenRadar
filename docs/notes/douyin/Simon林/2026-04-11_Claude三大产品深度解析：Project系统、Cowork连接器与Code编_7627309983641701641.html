1. 引言与产品概览

如果你只打开过Claude AI的网页，那我告诉你，你可能只用了它的三分之一。在同一个订阅中，Claude是能用这三个产品的。今天花8分钟给大家讲清楚每个产品是什么，然后该用哪个。这是Claude的三个产品，左边Claude AI，这个是网页版的，打开浏览器就能用。

2. Claude.ai：Project系统详解

它的杀手锏是Project系统，你可以给它一套专属的指令，然后加一个资料库，然后Claude就能跨对话记住一切。然后目前呢ChatGPT跟Gemini都没有这个功能。它的应用场景就是我们日常使用的场景，只不过比普通的传统的ChatGPT、Gemini多了一个记忆系统，能成为你的私人的专属助理，而且能够逐渐的迭代。

3. Claude.ai：Custom Instructions与

第一个是Custom Instruction，这是制定的命令，就是你可以给这个project一套专属的命令，Claude在所有的对话里都是遵守的。所以你不用每次都解释你的背景，这就相当于你给AI配了一份岗位说明书。你把这个直接去灌输，他每次跟你对话之前，他都会读这个instruction。第二个呢，就是project knowledge，它是整个项目的知识库，你可以上传PDF啊、Word啊、CSV啊、还有Excel啊、TXT这些所有的文件。因为这个东西很耗Token的，平时也不需要去加载，所以你不能放在第一部分的instruction里面。你可以在instruction里面告诉他，你碰到某一条法、那个法律之后，你去读这个knowledge里面的某个文档，这样就能非常精准的能解决你的一些问题，而不是说很多有幻觉的东西就会产生。所以这两个加起来，是一个跨对话持续的助手AI助手，而且它的instruction跟knowledge是可以升级迭代的。

4. Claude Cowork：桌面级助理与连接器

然后中间这个是Claude Cowork，这是桌面级的助理，它是装在你电脑上的，能够接管你电脑干活的Agent。而且它通过连接器，连接了50多个官方的软件，包括Word、Excel、PPT也都支持。它是全球最强打工人。它的应用场景就包括你可以自动的做Office，然后跨APP的一些任务。目前他有两个杀手级的能力，第一个能力是桌面级的接管，Claude AI是对话级的，然后Cowork它是整台电脑都可以给他管。他能够直接读写你的文件夹，自动完成浏览器的操作，然后还包括跨APP的多任务，都是可以的。他是一个真正能在你电脑上动手干活的员工。第二个能力呢，就是它的50多个连接器的生态，这都是官方的连接器，还包括Word、Excel、PPT、PDF这些。然后第二排就是一些这个飞书、Notion、Google Drive这些文件的系统跟沟通的系统。第三行就是GitHub这些编程用的。你用了Cowork就相当于你雇了一个能操作整台电脑，然后又能够懂你的打工人。

5. Claude Code：编程霸权与用户案例

最右边的是Claude Code，它是装在电脑里的编程AI。它的江湖地位现在就是世界第一，SWE的评分是80.8分。然后跑代码，然后跑命令，然后多AI，包括各种各样的部署的功能都可以用。目前它是开发者、技术用户还有Web Coding玩家的首选。它的地位是非常高的，它是全球第一的编程江湖地位。然后现在全世界顶级的AI玩家都在用它，编程跟AI玩家都在用它。包括前特斯拉的AI总监、OpenAI的创始人，他之前是用80%的自己的编程，用20%的AI，现在已经切换到80%的AI，20%的手动编程。我相信现在这是他可能一个多月前说的，现在可能又提升了。然后包括其他的玩家Samuel Wilson、Junkin这些全球Vibe Coding的头部玩家都在用它。它的SWE的评分，Claude的真实评分是全球第一的，已经超越了ChatGPT还有Gemini。我自己的使用，我现在已经开始把前面说的Claude AI的一些project直接转移到了Claude Code里面，因为它通过某种逻辑，它是能把知识库转移出来，然后Claude Code的逻辑也是能调用的。

6. 总结与下期预告

记住三件事：第一，Claude AI它是一个跨对话记忆系统，你可以使用这个Project把Claude变成你的私人顾问或者项目经理，这个都是可以的。然后第二，Claude Cowork是全球最强的打工人，能接管各种各样的Word、Excel、PPT，以后它有50多个连接器。然后第三，Claude Code它是编程AI的天花板，SWE 80.8%的分，大神们也是亲自验证的。然后下一期我会讲这个15分钟Claude Code的小白入门，欢迎大家关注我，我会持续更新Claude的深度实战内容，谢谢大家。
