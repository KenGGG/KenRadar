未来十年最值钱的能力是能动性（Agency）

一、内容简述

（一）一句话结论

一句话结论 视频指出在AI时代，单纯学习编程或AI应用可能很快被淘汰，真正决定个人价值和收入的核心能力是“能动性”（Agency）。引用硅谷创作者Dan Koe及哈佛、麦肯锡等机构观点，强调高能动性者能自主定义目标并利用AI放大效能，而缺乏能动性者将被视为高级执行工具。建议普通人通过“从不想做的事倒推”和“将人生视为实验”来培养主动性。

（二）核心内容

  1. 核心观点：能动性胜过技术技能 未来十年最重要的技能不是写代码或用AI，而是“能动性”（Agency）。硅谷创作者Dan Koe及多家顶级机构均得出此结论，神经科学也证实这是可训练的底层代码，而非天生特质。

  2. 现状分析：被动是默认设置 生活中80%的人处于被动状态，遵循社会既定规则，如同被“脐带”连接的社会。大脑在压力下倾向于等待指令，这是节省能量的出厂设置，但能动性可以通过后天复写。

  3. AI时代的影响：能动性决定杠杆率 AI消除了知识获取和行动障碍，使高能动性者能以十倍速度超越他人。缺乏能动性者即使拥有顶级AI，也只是执行具体任务的“高级牛马”；而有能动性者可将AI作为核武器，单人对抗团队产能。

  4. 行动指南：如何培养能动性 建议将人生视为游戏，不再等待NPC式的新手村任务。通过明确“不想要什么”来倒推方向，利用AI重做繁琐工作，将失败视为测试数据，从而强行覆盖大脑的被动设置。

2. 第一点：能动性的定义与社会陷阱

先说第一点，这最值钱的能动性到底是什么？三句话测试一下你是不是高能动性的人。第一，不会等着别人下指令才开始。第二，把生活呢当成一个巨大的实验，失败那不叫失败，那叫缩小范围。第三，看到困难呢就来解决，坚信自己能克服。你中了几点，评论区告诉我。你敢信吗？在我们的生活中，高能动性的人只占百分之二十，还不到那些每天埋头苦干，在公司的晋升通道里，拼命卷的人加在一起占了大约百分之八十。就是说你身边每十个人里就有八个，是在别人定好的规则里打转。Dan Koe的原话更狠。他说呢很多人随大溜回答，六就是你的心智还是像被脐带连接着社会一样。你以为是你自己在做选择？其实一直是在别人画好的格子里选了一个顺一点的位置站进去，真正问题也不是你占的哪一格，而是这张图纸从头到尾都不是你画的。学什么做什么什么算成功，什么算幸福。这些答案到底是你自己想出来的，还是社会替你填空之后，你慢慢的信了而已。但千万不要着急责怪自己，这根本就不是你的错。这是大脑为了节省能量的出厂设置，神经科学早就证明了，一旦遇到压力，大脑就分泌物质，把你死死按住，趴下不动，等别人派指令就是你的默认反应。所以呢被动是天生的。但幸运的是，能动性是你唯一可以后天复写进去的底层代码。

3. 第二点：AI时代能动性的价值倍增

第二点，为什么AI时代有能动性的人会越来越值钱？Dan Koe说，高能动性的人正在以十倍的速度超越其他人，成功比任何时候都要更容易，为什么呢？原因很简单，我们可以获取任何实现目标所需要的所有知识，行动的障碍，如今几乎不存在。就像我之前分享过的AI卖袜子的例子，所有的数据AI的能力，只要你有足够的能动性，就会发现以往的资源壁垒几乎完全消失。而你几十年来吃的苦积累的商业逻辑，加上AI就是你手里最好的牌，但现实也很残酷啊，Dan Koe说的非常直白，那些不会成功的人仍然不会成功，为什么呢？因为他们缺少能动性，他们在等等时机成熟，等自己做好准备，得有人指挥。但是在AI时代，最先被淘汰的可能就是这种只会等指令的人。因为论执行力，AI才是这个星球上最便宜最听话的超级员工。如果你的脑子里没有做决定的方向是个零，那哪怕给你最顶级的AI，你也只是个会用AI写精美周报的高级牛马。但是如果你有能动性，能自己定目标，那AI就是你的核武器，能让你一个人干翻一整个团队的产能。

4. 第三点：普通人如何练习能动性

再来到第三点，普通人到底怎么练出这种救命的能动性？Dan Koe呢给了一个极其扎心的比喻，把你的人生当成一场游戏。你想想看，打游戏的时候，十几之前都有新手村村长给你派任务。咱们的人生也是一样，上学、考试、找工作，每一步都有人告诉你，该怎么走，都有标准答案。但到了三十岁之后，你突然感觉被卡住了，为什么呢？因为再也没有人给你发任务了。那怎么破局呢？Dan Koe的方法极其粗暴，别再等别人给你发任务，你要自己来造句。那很多人会说，我根本就不知道自己想要什么，怎么造句，没关系，Dan Koe说的非常实在，没有人一开始就知道自己想要什么，但你绝对清楚自己不想要什么。不想在家无意义的班，不想被烂人烂事消耗，不想三十多岁，还要看老板的脸色过日子。好，那就从不想要开始倒推你的方向。从今天起，挑你手头最烦最耗时间的一项工作，试着用AI去重做一遍流程，不需要任何人批准，也不要怕搞残。把所有失败呢都当成你这场游戏的测试数据。当你不再是一个被动阶段的NPC，而是主动的在给自己设计关卡的时候，你就是在强行的覆盖大脑的出厂设置，命运的齿轮就开始转动了。好了，等过这篇万字长文推荐给大家，对文字版感兴趣的朋友评论区告诉我，我是竹子，关注我，快进一步把握AI时代机遇。
