（二）核心内容

  1. 市场背景与核心策略 本轮牛市表现强劲，近期基金连续正收益，单周最高收益超四万元。在牛市中赚钱主要依靠两招：只做主线、不做杂毛；以及买完不看、坚定持有。

  2. 科技主线及迂回投资法 今年主线为科技，龙头包括芯片、半导体和光模块。鉴于直接追高个股风险大，建议采用迂回策略，购买涵盖这些行业的指数基金，如创业板指和科创50，实现资金分散，降低单一板块风险。若认为上述指数仍偏高，可考虑包含更多科技潜力股的中证500和中证1000指数，虽涨幅可能不及前者，但风险更分散。

  3. 非主线板块分析与操作建议 上轮牛市主线为消费和医药，本轮表现较差。散户常因抄底低位板块而偏离主线。但在牛市中期，低位板块也会上涨，若已持有可不卖出，等待牛市后期分享红利。

  4. 心态管理与长期持有 第二招是买完不看、坚定持有。举例显示，部分粉丝因忘记持仓或仅投入少量资金，反而获得极高收益（如218%、147%），而频繁操作重仓者收益不佳。强调在牛市主线中，减少操作频率、长期持有是获取高收益的关键。

1. 市场表现与核心策略概述

这轮牛市还挺波澜壮阔的，在这个月每天都是正收益，基本都是在一万元左右，甚至在上周五是收益来到了四万加。想在牛市中赚钱，其实就两招，第一招叫做只做主线，不做杂毛。

2. 科技主线与指数投资方案

今年的主线是什么呢？毫无疑问就是科技。而其中的芯片、半导体和光模块肯定是龙头中的龙头。但如果让你现在去追的话，肯定是不敢的。所以我们可以采用迂回操作的策略。光模块和半导体属于什么指数呢？就是创业板和科创五零。如果我们买创业板指数和科创五零的话，相当于一次性打包了几十家甚至上百家公司。通过买指数的方式，把资金分配到很多家公司上，这样比买单一板块肯定相对风险是更低的，我们心里也是更好受的。或者你看创业板指和科创五零还是高，那么你就去买更宽的一些指数。中证五百和中证一千这两个指数包含的是a股中等或者偏小市值公司的指数。这里面就包含了不少科技股，或者说是未来发展潜力不错的公司。不过因为这两个指数没有更加的聚焦科技，所以上涨的幅度是比不上创业板和科创五零的。

3. 非主线板块表现与持仓建议

那不做杂毛怎么说呢？像上轮牛市的主线是消费和医药，在这轮牛市的表现其实还是蛮差的。只要牛市还继续上行，科技还会虹吸这些板块的资金。很多散户是摆着主线不做，而是去抄底这些低位板块。不过在牛市的中期，这些相对低位的板块也会上涨的。如果你已经是持有了，也可以不卖，等到牛市的。最终这些板块也是可以去分享牛市的红利的。

4. 坚定持有与心态调整

牛市操作的第二点叫做买完不看坚定持有，就这个说起来是最简单的，但实际做起来还是蛮难的。我们来看一张辉哥粉丝的持仓图片啊，能看到它的收益率是非常高的。百分之二百一十八，百分之一百四十七，百分之一百三十七。我相信这个收益率已经超过了大部分人了。但是看他的持仓就只有几块钱，这就是很多人的现实。我买了几块钱，我都忘了一个基金了。然后一年后打开发现基金赚了很多钱，我频繁操作，重仓这支基金反而是不赚钱。有这个情况了，可以公屏打个一看看。所以买到牛市的主线，坚定持有不去看，是牛市中赚钱非常重要的一点。好的，最后希望大家都能在牛市中赚到钱。关注辉哥，下期视频更精彩。
