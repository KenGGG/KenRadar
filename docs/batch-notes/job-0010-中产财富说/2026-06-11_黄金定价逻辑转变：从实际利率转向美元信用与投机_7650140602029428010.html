黄金定价逻辑转变：从实际利率转向美元信用与投机

一、内容简述

（一）一句话结论

一句话结论 文章指出黄金定价逻辑已发生根本性变化。2016年前，黄金价格与美元实际利率呈强负相关，与美元指数呈负相关。2016年后，这一逻辑失效，黄金与美元转为正相关。2024年以来，尽管实际利率震荡，金价却翻倍，主要驱动力转变为美元信用受损（央行增持、美债规模扩大）以及市场投机情绪。作者警告脱离基本面的上涨最终将由新入场的投机者接盘。

（二）核心内容

  1. 市场情绪与人性分析 黄金跌去今年所有涨幅。作者回顾1月31日预测下跌的视频，指出人性情绪化，投资者倾向于听取利好信息，忽视利空。强调在狂热市场中，客观分析往往被忽视，投资者需经历亏损才能回头。

  2. 历史定价逻辑：实际利率主导 2020年之前，黄金定价主要看美元实际利率预期。金价与美元实际利率相关系数达0.89（强相关）。持有黄金的机会成本是放弃国债利息（名义利率减通胀）。实际利率下降时，黄金保值属性增强，价格上涨；反之则下跌。

  3. 逻辑失效：美元与黄金关系逆转 1971-2015年，黄金与美元呈稳定负相关（系数-0.52）。2016年后，两者转为正相关（系数0.45），传统定价逻辑失效。这导致黄金与美元出现同涨同跌现象，颠覆了过往学术结论。

  4. 当前驱动因素：美元信用与投机 2024年以来，实际利率（TIPS收益率）在1.6%-2.3%震荡，但金价从两千多涨至五千多。主要原因包括：1. 美元信用受冲击，美债规模逼近40万亿，央行增持黄金以突围石油美元体系；2. 投机属性主导，赚钱效应吸引新入场者击鼓传花，风险在于最后接盘的新手。

2. 外汇风险提示与历史定价逻辑

我自己接触黄金大概是在二零一四年左右。因为在一四年的时候，在上大学的暑息肯到了接触了这个外汇交易。在这里呢就跟年轻的学生提醒一句，国内所有外汇都都不要去碰，因为百分之九十五都是杀猪盘。因为你赚的钱是做市商亏的钱。你和做市商之间是零和博弈，除非你能开导那些真正能把你单子扔进市场的交易商。但在国内也是开不倒，也不要去找类似于外汇交易的工作，除非这个人头铁就想体验体验什么是社会的险恶。在十二年以前，一直到我印象中中二零二零年之前，黄金金交金和美实际利率量就是美元利率。当时只要盯美美利利率预期的变化，也是只要盯加利息息息的预化，注意不是实际的息息降降息，而预预期，这变变是利率变化的。二阶导数，根据招商量化的研究，金价与美元实际利率率间的相关系数达到了零点八九。在统计学中呢，零点八九属于强相关，等于说就是黄金和美元实际利率之间几乎就是一个线性的关系。所以如果你在二零年之前是炒黄金，你只要能看懂美联储加息降息的预期变化，那你大的方向上就不会出错。

3. 美元与黄金相关性变化及原理

刚才我们说的是黄金与美元的实际利率，但黄金和美元之间的关系就要相对弱一些。这里需要注意的是，美元和美元实际利率是两个变量。根据光大证券研究所的结论，黄金和美元之间的相关性，在一九七一年一直到二零一五年一直呈现稳定的负相关关系。这和我们刚才说的黄金与实际利率之间的关系是相同方向的，相关系数也达到了负的零点五二。但是自从二零一六年之后，黄金与美元之间的关系开始出现了变化，就是由负相关转为了正相关，相关系数达到了正的零点四五，这是一个非常让人困扰的事儿。因为这意味着我们过去几十年来依靠黄金美元之间的定价逻辑已经失效了。以前黄金的涨跌逻辑是看美元，因为黄金本身不产生任何的利息，而债券这里特别指的是美国国债能够产生利息，持有黄金的成本，就等于是放弃了国债的利息。我们这里说的利息就是名义利率减去实际通胀之后的实际利率。所以当实际利率下降的时候，持有黄金的机会成本就会消失。那现金和债券的购买力就会缩水，黄金的保值属性就会增强所有黄金的价格上升。那逻辑反过来，实际利率上升的时候，持有黄金就变得不划算了。因为持有国债能够拿到更高的利息，所以黄金的价格就会下跌。注意上面我们说的这个关系，在二零一六年至今的十年中已经失效了。所以在这十年中才有了很多黄金和美元同涨同跌的现象，而这也完全颠覆了很多学术研究中的结论。

4. 2024年以来的异常行情与原因分析

特别是自从二零二四年以来，美国十年期的tips,收益率俗称十年期通胀保值债券。收益率可以就等同于是实际利率，这个变量在过去的纪念间一直是在一点六到二点三之间来回的震荡。也就是说实际利率并没有出现显著的上行或者下行。自二四年以来，但同期的金价却出现了翻倍的行情，从两千多涨到了五千多。为什么会造成这种现象呢？首先，第一黄金自从二三年底一直到二五年一月的行情中，这段行情中定价逻辑更高的是美元信用的权重。在这个阶段中，我们听到的更多的新闻都是全球哪些央行又增持了黄金，为什么全球央行会选择增持黄金呢？因为美元的信用受到了冲击，美债的规模逼近了四十万亿。再加上国际贸易上，美国对制裁国家的一些限制，让美元的权重出现了下降。其实，这些年以来，我们一直在尝试从石油美元体系中突围，将货币的定价权从石油转向新能源。包括前两天视频中我们说的比特币出现的意义，都是为了打破美元的垄断，创造一个新的去中心化体系。当然，除了上面说的逻辑以外，都了涨幅的解释只能用黄金的投机属性来解释了。因为当脱离实际、利率、美元、信用等定价权重之后，黄金无法理解的一些涨幅都可以说是投机因素，也就是赚钱效应吸引了更多的人入场击鼓传花，最后疯狂到博场，一直没有最后一棒棒接盘，最后该接盘的都接盘的一知崩崩盘，谁会会是图途中的后后一棒人？肯定不会是咱们这些之前亏过钱的，也就是咱们这些涨过记性的，一定是那些刚入场心怀憧憬一年想赚个属性的那些人，这些人一定也是当初骂黄金下跌最狠的人。因为当初我说的这些东西和他们的持仓利益是相反的，你说任何人会亏钱，谁不爱听都会骂你是傻逼。因为每个人在进入到金融市场之初，都是幻想着自己的能从这里赚到大钱。但最后你能不能拿走这笔钱，就要看你这个人的修行和德行了。
