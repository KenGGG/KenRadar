  4. 神经机制与打破循环 大脑杏仁核（恐惧）在前额叶皮层（理性）之前启动，导致焦虑-拖延-暂时缓解-更大焦虑的循环。打破方法一：不问准备够不够，只问做没做（如写作即动笔）。方法二：建立真实社会连接，通过创造价值确认自我价值，从而不再恐惧失败。

1. 拖延的本质与伪生产力

很多人以为执行力差是因为懒，但真实情况恰恰相反。根据美国心理协会的调查，不过，百分之六十的拖延者并不是因为懒，而是因为焦虑和自我怀疑。他们不是不想做，而是越想做好，越不敢开始。如果焦虑，为什么不直接去做呢？很多人没意识到人类的大脑有一个非常诡异的机制，我们会主动选择用假行动去代替真正的行动。什么意思呢？比如你本来要打算写一篇文章，但你先去报名买了一个写作课，还要做自媒体。但你研究平台算法研究了半年。本来要创业，但你又去花大量的时间去做行业调研，这些事情看起来都很正确。但问题是，他们并不直接产生结果。心理学家给这种行为起了一个名字，要生产力是拖延，就是看起来很努力。实际上，在逃避哈佛大学有一个著名的实验研究者发现，拖延者最常见的行为不是摆烂，而是去做次要任务。比如该写论文的人去整理桌面，填写报告的人会先去回复邮件，该创业的人会去看一堆商业书。这些行为有一个共同点，看起来很努力，但不会产生风险，就是执行力。问题的核心不是懒，而是去逃避不确定性。

2. 经济视角与自我设障

从经济学角度看，逻辑很直接。在真实世界中，任何行动都有成本，创业可能失败，写文章可能没有人看做项目，还可能亏钱。但如果你一直停留在准备阶段，你就永远不会失败。你会发现一个特别有意思的现象。很多人每年都会说一句话，我要创业了，我要开始做副业要转型了。但三年过去了、五年过去了、十年过去了，他们依旧在研究的阶段。我身边一个朋友去年开始说要健身，他说这次一定有结果，所以先买了跑鞋，办了健身卡，买了衣服和蛋白粉，但每周还是三天打鱼两天晒网，坚持了两周，最后没有任何结果，还是放弃了。还有一个朋友说上班没发展，准备创业，做餐饮，第一天说要做鸭货，第二天说要做炒菜，第三天又要去说做早点，每天都很忙，每天都在研究。但一年过去了，还在原地踏步，没有任何实质性的开始。这是一个非常典型的心理现象，总是在脑子里想象一直在准备，一直在学习，但就是不真正的开始。为什么会这样呢？因为这样有一个巨大的心理收益，你可以一直维持自己不失败的人设可以维持。我本来是可以成功的，只是我没有真正去做，这是一种非常舒服的叙事。不是我不行，只是我没开始，但如果你真的开始了，你会出现两个风险。第一个风险，你可能失败。第二个风险更可怕。你可能成功，但没有想象中成功。比如你创业赚了五十万，听起来不错。但在互联网时代，大家都在讲上市融资独角兽，你会发现你的成功在网络上一笔好像也不算什么，是很多人选择了一个更安全的状态，永远停留在准备阶段，这样就不会失败了，不会暴露真实的能力。心理学家把这种现象叫做自我设障，简单说就是提前给自己找一个借口。如果未来失败了，原因不是我不行，就是我没有认真去做哈佛大学。有个研究发现，很多学生在考试前故意不复习，是因为他们不在乎成绩，而是因为如果考砸了，他们可以说我没复习，这样可以保护自尊。

3. 商业决策与神经科学解释

同样的逻辑，在商业世界中也适用。很多创业者喜欢不断的调研，不断学习，不断规划，不断准备，但就是不推出新的产品。为什么？因为一旦产品上线，市场就会给出真实的反馈，真实反馈往往非常残酷。我们以为自己做的是需求，结果市场根本不买单。我们以为自己的产品很牛，结果用户根本不买账。你会发现一个商业世界的规律，真正赚到钱的人往往行动非常快。比如亚马逊的创始人杰夫贝索斯，还有一个非常著名的决策原则，叫百分之七十原则。什么意思呢？当信息掌握到百分之七十，就必须做决策。如果等到百分之百机会早就没了，因为商业社会有一个残酷的事实，信息收集是有成本的，每拖延一天你就会损失一个机会。所以很多创业者遵循一个逻辑，先做再改，不是先完美。这也是为什么硅谷有一句非常经典的话，完成比完美更重要。再说一个更深层的原因，为什么拖延会让人上瘾？答案在我们的大脑结构里，内个大脑有两个重要的系统，一个叫前额叶皮层，负责理性和计划，一个叫性仁和，负责恐惧和情绪。当你面对一个困难任务的时候，杏仁核会先启动，他会告诉你有危险，可能失败可能丢脸是大脑就会寻找一种方式去缓解我们的焦虑。最简单的方式是什么呢？做一些看起来有用的事情，比如看书、整理资料或研究方法，这些事情会让你产生一种错觉，我在前进，但实际上，我们在原地踏步。经科学研究发现，波眼会形成一种循环焦虑，拖延暂时缓解更大的焦虑。久而久之，大脑就会形成一种习惯。这也是为什么很多人越拖越严重。

4. 解决方案与社会连接

那问题来了，怎么打破这个循环呢？先讲第一个原则，不要问准备够不够？问一件事儿，我们到底做还是没做？写作的人不写，就是没准备。创业的人不卖产品，就是没准备。做自媒体的人不发内容，就是没准备准备不是目的，结果才是再讲。第二个更深层的方法。心理学家阿德勒曾经提出过一个观点，人类的很多逃避行为是来源于自卑感。当一个人不确定自己有没有价值的时候，他就会害怕失败，因为失败会证明一件事儿，我真的不行，那怎么解决呢？德多乐给出的答案非常简单，建立真实的社会连接。简单说就是去创造自我价值，去连接真实的社会。当你在现实社会中不断的产生价值，你就会慢慢的建立一个新的认知。即使这件事儿失败，我依然是一个有价值的人，那你就不会害怕真正的开始。所以你会发现一个很有意思的现象，很多真正成功的人并不是最聪明的人，而是最敢行动的人。他们理解一个底层规律，现实世界只奖励行动，想法不值钱，计划不值钱，调研也不值钱，只有行动才会改变。结果你现在最想开始，但一直没有行动的事儿是什么？评论区交流。
