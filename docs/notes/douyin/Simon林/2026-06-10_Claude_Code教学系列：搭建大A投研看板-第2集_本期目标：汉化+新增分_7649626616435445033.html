（二）核心内容

  1. 项目背景与目标 基于第一期搭建的Web Trading应用，利用Claude Code进行二次开发，目标是打造个性化的投研看板，实现界面汉化、功能扩展及数据可视化。

  2. 第一步：界面汉化与品牌定制 在原有项目目录下打开Claude Code，发送指令要求将侧边栏、首页、按钮、菜单等所有英文文本翻译为符合中文习惯的用语，仅修改文字不动功能。同时将左上角品牌名“Web Trading”修改为用户自定义名称，并验证页面正常打开。

  3. 第二步：新增导航分栏 向Claude Code发出指令，在左上角导航栏顶部新增“总览”和“人形机器人”两个空白页面分栏，明确要求保留原有栏目不删除。AI执行后，导航栏即显示新增的两个自定义入口。

  4. 第三步：构建总览看板核心功能 分三小步实现总览页：1. 搭建指数卡片，展示A股和美股指数实时点位及涨跌幅（红涨绿跌）；2. 创建两列自选股模块（A股接AKShare数据，美股接yfinance），支持手动添加代码和名称；3. 在右上角增加刷新按钮，点击可更新所有数据。
