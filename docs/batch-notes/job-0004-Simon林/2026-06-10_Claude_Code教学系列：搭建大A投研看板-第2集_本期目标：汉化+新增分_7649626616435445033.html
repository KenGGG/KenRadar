  1. 项目背景与目标
    基于第一期搭建的Web Trading应用，本期目标是将其改造为个人投研看板。具体任务包括：界面汉化与改名、新增导航分栏、搭建总览页面（含指数实时数据、自选股列表及刷新功能）。

  2. 第一步：界面汉化与品牌定制
    在原有项目目录中打开Claude Code，提示其将侧边栏、首页、按钮、菜单等英文界面翻译为中文，并修改左上角品牌名为自定义名称。要求仅修改文字，不改动功能逻辑，并确认应用正常打开。

  3. 第二步：新增导航分栏
    提示Claude Code在导航栏左上角新增“总览”和“人形机器人”两个空白页面作为分栏，要求保留原有栏目不删除。Claude Code执行后，导航栏顶部将显示新增的两个栏目。

  4. 第三步：搭建总览页面功能
    分三步实现总览页面：1. 搭建指数卡片，显示A股和美股指数的实时点位及涨跌幅（红涨绿跌）；2. 搭建两列自选股，A股数据接入AS CK Data，美股接入Y Finance，每列上方增加添加按钮；3. 在右上角增加刷新按钮，点击可更新所有数据。

  5. 调试与后续计划
    若出现数据显示错误或功能异常，需截图或复制错误信息反馈给Claude Code进行修复。作者表示将持续更新各模块搭建及研报拉取等内容。
