## P5 检索与转录边界

新增可重建的私有 FTS5 trigram 索引，三字以上可利用索引，短词和特殊字符继续转义 LIKE。原始转录可搜索但不进入列表正文。中文、短词、英文、百分号、下划线、引号、更新触发器和重建测试通过。

一万条独立样本基准位于 `data/test-migration/query-benchmark-20261010/query-report.json`。30 次采样的 p95 约 21–51ms；高命中样本中索引反而较慢，因此未默认启用，也不外推生产表现。

Pagefind 仅接收明确 HTML 路径和 SHA 清单，先全部验证再生成新目录；实际二进制及浏览器验证中文短词命中，未批准页面和秘密文件未进入预览。没有向互联网发布。

修复 FunASR 与 Whisper 开关独立性；可选转录校正不覆盖原稿。使用现有打包 FFmpeg 真实处理中文空格路径的一秒合成视频，输出单声道 16kHz 音频。当前 PyTorch 为 CPU 构建，GPU 转录、真实语音精度、字幕优先和本地媒体导入尚未验收或实现，不引入新模型冒充可用。
