1. **Qlib 框架核心优势**  
   Qlib 在 GitHub 量化研究领域排名第一，拥有 4.1 万 Star。主要优势包括：1. 开箱即用的因子库，包含 158 个量价指标和 360 个时序原始特征；2. 自研二进制数据引擎，读取速度比 Pandas 快十倍；3. 微软官方出品，持续更新。

2. **Qlib 功能与竞品对比**  
   Qlib 主要功能包括因子筛选、收益率预测、历史回测（支持20年数据）及报告输出。相比其他停更或半死不活的量化模型（如某些旧项目），Qlib 生态更活跃。但相比 BNPY 等工具，Qlib 缺乏直接对接交易的 API 接口，不适合直接实盘交易。

3. **Qlib 的局限性**  
   Qlib 的弱点包括：1. 门槛较高，需懂量化研究和机器学习；2. 无 API 对接，无法直接实盘；3. 仅支持截面标的策略，不适合 CTA 策略；4. 文档较多且抽象，学习成本高。

4. **Claude Code 辅助工作流**  
   利用 Claude Code 解决 Qlib 的使用痛点：1. 自动拉取仓库并搭建环境，解决 Python 版本冲突、依赖链安装及系统兼容问题；2. 数据格式转换，将 AKShare 或 iFinD 获取的数据转换为 Qlib 二进制格式；3. 辅助模型迭代与回测，如测试特定策略（如“北京炒家”打法）或调整市值范围（如30-50亿以下小盘股）。

5. **总结与建议**  
   工作流总结：数据由 AKShare 或 iFinD 提供，流水线由 Qlib 处理，AI 副驾由 Claude Code 担任，策略方向由用户自行决定。视频强调此为开源工具与 AI 编程演示，不构成投资建议。
