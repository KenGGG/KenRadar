Hello，我是卓叔，很多手指骨架偏小，天生肩部很窄，显得整个人很细，就像麻杆一样。但我们只要把肩部练大，小骨架也能拥有大肩宽。肩部指的是胳膊最上方这块三角肌。我们把它分为前束、中束、后束三个部位，分别安排针对性的训练。

2. 前束训练原理分析

首先是三角肌的前束，非常适合使用大重量进行爆发力训练。原因有这两个。第一，三角肌是羽状肌，特点是生理横断面大于解剖横断面。横断面就是同样粗细的肌肉里，羽状肌收缩的肌纤维数量要更多。所以三角肌的力量要比一般的肌肉更强，本身就更适合大重量、低次数的训练方式。第二，三角肌前束的训练基本都和推有关。例如杠铃推举、史密斯推举。另外大家不容易留意到的知识点是所有和推有关的肌肉都是动力型的，肌肉很适合上大重量。

3. 训练执行细节

所以在练肩前束的时候，我们可以这么做。第一，为了保证重量足够大，我们应该把每组力竭的次数控制在六到八次左右，这就是大重量训练。第二，在推起杠铃的过程中，我们要用最快的速度把重量往上推上去，这种爆发力的方式非常适合三角肌的特性。例如有个动作叫做借力推举，利用腿部的力量，把更重的杠铃推起来，也是一种爆发力的练法。第三，组间休息时间可以更久一点，每组休息个两分钟都没有关系，让力量充分恢复下一组，就能够继续挑战大重量。

4. 总结与预告
