一、内容简述

（一）一句话结论

一句话结论 本视频针对新手投资者，讲解如何利用同花顺APP快速查看和分析财务报表。重点介绍了基本面分析的三大核心报表：利润表（关注营收、毛利率、归母与扣非净利润）、资产负债表（关注资产负债率、存货、应收账款）及现金流量表（重点关注经营活动现金流）。核心观点是财报主要用于排雷和验证真假，而非单纯估值，强调‘利润是账，现金是事实’，通过三表联动判断公司主业健康度及潜在风险。

（二）核心内容

  1. 财报分析的核心目的与工具入口 财报对短线选手而言主要用于排雷和看清真假，而非精确估值。新手可通过同花顺手机界面下滑至简况F10，选择财务分析，进入常用指标查看更多数据。

  2. 利润表关键指标解析 锁定四个关键词：营业收入（判断盘子是否实打实扩张）、毛利率（判断成本降低或利润回暖）、归母净利润（含一次性收益如卖资产）、扣非净利润（剔除一次性收益后的主业真实盈利）。若归母大涨但扣非下跌，则为假增长。

  3. 资产负债表风险排查 锁定三个关键词：资产负债率（需结合行业平均水平，周期反转时高负债是隐患）、存货（上行周期为硬资产，下行周期巨额存货面临减值风险）、应收账款（警惕通过关联交易虚增营收和利润，导致资金未实际回笼）。

  4. 现金流量表的‘照妖镜’作用 重点关注经营活动现金流。利润可采用权责发生制粉饰，但现金流难以造假。长期来看，扣非净利润应与经营现金流匹配。高利润低现金流如同‘吃香喝辣却还不上信用卡’，暗示财务造假或盈利质量差。

  5. 综合判断逻辑与案例回顾 通过三张表筛选出四个信息：1.营收确认生意真实扩张；2.双净利润确认主业非一次性收益；3.毛利率判断盈利质量并串联估值；4.存货、负债及现金流判断风险。以江波龙为例，应用此逻辑理性判断其异常数据。

2. 利润表：营收、毛利与净利润辨析

第一张表利润表，我们锁定四个关键词，分别是营业收入、毛利率、归母净利润、扣非净利润。营业收入就是毛利润，它的正增长，一般情况下代表你公司盘子实实在在的做大了。注意是，一般情况下，说明公司的营收是整体销量出货规模实打实的扩张了。但如果毛利率也持续走高，那要么是你生产成本大幅降低，要么是你产品利润大幅回暖。归母净利润就是这个百分之六万，这个数据的统计口径啊，所有净收益都计算在内，包括卖楼、卖地、卖子公司等等的一次性利润。而对应的扣非净利润，全称叫扣除非经常性损益后的净利润，意思就是把卖资产、拿补贴等等这些一次性收入全扣掉之后，主业真正赚了多少钱。判断标准也很简单，如果扣非净利润连续多个报告期上涨，说明主业经营的还不错，总之是越赚越多。了归母净利润大涨，但扣非不涨，甚至下跌，那就是假增长。比如上期视频提到的赛微电子。

3. 资产负债表：负债、存货与应收账款陷阱

第二张表资产负债表，利润表反映的是公司某一段时间的表现，而资产负债表反映的是某一个时间节点上公司的全部家底和负债。这张表我们锁定三个关键词，分别是资产负债率、存货以及应收账款。首先看资产负债率，比如这个数字是百分之六十，那就说明这家公司的负债占总资产的百分之六十。而负债规模的大小，要结合行业平均水平来看，行业景气阶段依靠杠杆放大盈利无可厚非，但如果周期反转，远高于行业平均的负债是绝对不容小觑的隐患。存货规模的大小就是说你仓库里堆了多少货。在行业上行周期里，存货多，那叫硬资产，越放越值钱。可一旦到了下行周期，手里如果还有着巨额存货，就意味着公司需要面临对应的巨额计提减值，这属于中长期风险。最后应收账款这一项就很棒。你看如果我的公司有堆积如山的滞销产品，我把他们以极高的价格卖给一家表面上毫无关联，实则也是我暗中控制的空壳公司，只要签了购销合同，哪怕空壳公司一分钱定金没有付，我的财务报表上也会立刻凭空多出一大笔营业收入和净利润。实际上这些钱全变成了躺在账上的应收账款。当期财报，你们一看，哇，这家公司业绩无敌，疯狂买入。我呢就趁着股价被推高时减持套现，过几年当做坏账一计提，屁事儿没有，无非就是把你们散户套上了。

4. 现金流量表：检验利润真伪的照妖镜

而第三张表现金流量表，这里我们只定一项叫经营活动现金流，也就是日常做买卖回笼的现金。这项俗称财报里的照妖镜。老股民常说，利润可以做账，现金流骗不了人。是的，因为利润采用权责发生制，货卖出去就计算到利润里，哪怕没收到钱。但现金流只认实打实到账的现金。在现代企业复杂的会计制度下，想要粉饰净利润，对于那些精明的财务人员来说，简直好比你开个美颜瘦脸还简简单单，但这一指标几乎无法造假，哪怕是华尔街最顶尖的做账高手也无能为力。这里大家记住一句话，利润是账，钱，现金才是事实。这是古老而颠扑不破的真理。长期的扣非净利润要持续匹配经营现金流。高利润、高现金流，那叫真富有。那就好，比一个人天天吃香喝辣的，信用卡却总是还不上，这他底真钱是假有钱。

5. 总结：四步筛选法与案例应用

三张表总结来讲呢，那我们筛选出的这些数据，就是帮我们判断出四个信息。一是通过营收确认公司生意是否真实扩张，而不是单纯的利润跳涨。二是通过两个净利润观察，确认其主业利润不能是一次性收益。三是通过毛利率判断盈利质量，从而串联刚学的市盈率估值。四是通过存货、负债率以及现金流来判断有无暗藏的风险。以上数据都达标，就可以说明这家公司基本面起码是健康的。但如果任何一项亮了红灯，都需要管住自己的小手谨慎对待。那到此为止，我们再回头看江波龙的爆炸数据，大家就可以按照这个思路对其进行一波理性的判断。机油非常期待大家的答案。好，以上就是本期视频的全部内容，希望能够帮助到大家。我是机油，祝大家投资之路长虹，我们下期再见。
