（二）核心内容

  1. 项目概况与核心定位 Vibe Trading是由香港大学开源的金融Agent操作系统，上线约一个月，GitHub Star数超过7000。其核心定位不是单一的金融软件，而是一个能够理解用户意图并自动调度资源的Agent OS。系统架构合理，包含30多个工具、72个技能文档、452个因子及7个跨市场回撤引擎，支持大A、美股等多个市场。

  2. 核心工作流程与ReAct机制 系统采用ReAct（推理与行动）循环机制。当用户提出分析需求（如分析茅台），Agent会先思考所需工具和数据，编写代码并执行，随后评估结果。若结果不满意，系统会重新思考并调整，最多循环50轮。这种机制确保了产出质量较高，能够自动完成从数据获取、代码编写到回测执行的全过程。

  3. 工具生态与技能库 系统内置30个零配置工具，涵盖回测、因子计算、代码知识加载、影子账户等。72个Skill通过目录加载，包含数据接口、技术分析、策略模板及工作流指南（如报告写作、团体协作）。当对话中出现相关关键词时，Agent会自动调用对应Skill，实现全面的金融分析支持。

  4. 代码生成与多市场回测引擎 具备代码生成能力，用户可通过自然语言描述策略（如双均线测试），系统自动生成Python代码并交由回测引擎执行。回测引擎已集成A股、美股、港股、期货及外汇等跨市场规则，无需用户手动强调交易规则，系统会根据标的自动匹配相应市场的回测逻辑，支持超短线、波段及中长线策略。

  5. 高级功能：上下文管理、多Agent协作与影子账户 系统提供五层上下文压缩管理，确保长对话不丢失关键信息。拥有33个预设的多Agent专家团队（如宏观、首席、技术、量化实验等），可并行处理复杂分析。特色功能包括‘影子账户’，用户上传真实交割单后，系统可挖掘盈利规律并进行归因分析，辅助优化交易策略。
