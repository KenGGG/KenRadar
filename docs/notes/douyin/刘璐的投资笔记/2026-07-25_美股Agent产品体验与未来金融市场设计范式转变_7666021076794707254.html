1. 产品体验与信息处理痛点

这次我还专门去了一趟市马特，见了一位做金融交易，还有投资真人体的创始人。他们现在呢开始做了一个美股的agent这个产品，我自己体验了一段时间。坦白讲，他确实帮我省掉了大量的这种关于搜集啊，还有整理啊，包括交叉验证的这个时间。因为我一直是结合着美股，还有a股之间的这个产业的映射在做这件事儿。最难的从来不是说找不到信息，而是每天面对的信息实在是太多了，各个软件根本就忙不过来。包括海外公司，还有上下游的产业链、宏观政策、财报、数据、市场交易等等。任何一个环节发生的任何一个变化，都有可能影响最后的一个变化。以前是每天天不完，现现在有了呢，至少说可以先帮我筛选一部分重点啊，梳理一下逻辑，发现一些异常。

2. 创始人观点：服务Agent而非仅服务人

吃饭的时候呢，我问了这位创始人一个问题，我说你们这个产品最终服务的到底底个个投资资者还机机构投资？没想想呢，他给了我一个比我的问题根终服掉的一个回答。他说未来呢我们考虑的可能不是说服务个人还是机构考虑的是我是服务人还是服务agent.

3. 市场趋势：金融产品设计面向机器调用

所以你看看啊，当我们很多人还在比较说我们的这个APP里面，豆包、芥m贷，还有cloud,哪个好用的时候，硅谷那儿已经在考虑另外一个问题了。就是当大量的agent进入到了金融市场，未来的信息交易，还有金融产品，究竟是涉及给人看的，还是设计给机器去调用的那这背后改变的可能不是一款工具，而是整个金融市场的一个参与方式。

4. 结论：投资者需掌握工具调用能力

这个认知差啊，顿时给了我狠狠的一击。我越来越确定一件事儿，就是未来的投资者不一定说每个人都要成为专业研究员，但一定要学会调用一些专业的工具。
