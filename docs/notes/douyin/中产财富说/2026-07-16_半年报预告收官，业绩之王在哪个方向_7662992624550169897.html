  4. 未来主线线索与预期交易警示 华泰证券给出三条线索：一是AI产业链（存储、PCB、光模块）业绩确定性强但股价已阶段性透支；二是涨价逻辑（如锂盐企稳回升、化工品价格修复）带来弹性利润；三是制造业出海凭借全球份额与成本控制实现稳健增长。此外消费领域出现困境反转信号，种植业回暖但生猪养殖仍低迷。需注意业绩好不代表股价涨，市场交易的是预期而非过去数据，高位业绩利好可能兑现为利空，低位超预期才是真机会，需结合股价位置综合判断。

2. PCB板块业绩预增与新能源上游回暖

不仅仅是存储，PCB板块的业绩预增同样亮眼，比如沪电股份的预计净利润同比增长百分之六十八到百分之七十八。深南电路预计净利润同比增长百分之五十四到百分之六十九。但是业绩预告中还有一个非常明显的分化，比如新能源方向上游锂资源的业绩大幅回暖，比如天齐锂业的锂产品均价同比大幅上涨，上半年的净利润同比预增百分之三千二百七十六到百分之四千九百三十五。

3. 汽车、光伏与房地产板块承压亏损

但是汽车板块依旧承压，通威股份预计上半年净亏四十八到五十四亿，容百科技预计亏损三十四到三十八亿。也就是说，光伏行业供需失衡的局面仍然没有得到有效的改善。那房地产板块的情况更加糟糕，经济股份（原文未明确说明具体名称）预计上半年亏损二十四到二十九亿。绿地控股预计上半年亏损三到四亿，同样汽车板块也有着不小的问题。广汽集团预计上半年亏四十点六到四十五点七亿。赛力斯的规模净利润预计亏损十五到十八亿。

4. 券商板块利润创新高与红利属性转变

但是券商板块的利润与增却同比逆势上涨。中信证券预计上半年增长百分之六十九点五九，创下了同时期的历史新高。国泰君安和海通证券预计二百到二百零五亿，同样创下了半年业绩的历史新高。但是券商板块自二五年的八月以来，最大跌幅超过了百分之二十。七点六和大盘指数相比呢出现了明显的分化。核心的原因就在于，券商正在从高速增长期过渡到了红利属行阶段，就像当年的银行板块零六到零七那一年，牛市弹性极高。但是到了一三到一五年，银行就逐渐变成了高股息的红利资产。现在券商也是一样，盈利规模在逐渐增长，但是股价没有跟上，所以它的股息率就在抬升。目前券商板块的股息率大概在百分之二左右。随着业绩的持续增长，券商的股息率还会往上继续走。

5. 未来发酵方向线索与预期交易逻辑

那未来哪些方向会继续发酵呢？华泰给出了三个线索，分别是AI涨价，还有制造。第一，AI产业链需要精挑细选存储PCB光模块。这些方向虽然业绩的确定性最强，但是股价已经阶段性的严重透支。第二呢是涨价逻辑。比如目前锂盐价格的企稳回升，只有化工产品的价格修复，这些都是涨价带来的弹性利润。只要上一级的涨价趋势还在，那么业绩就还有空间。第三就是制造业出海。一些出海优势明显的制造业，依靠全球份额还有成本的控制，实现了稳健的增长，这些都属于更长期的逻辑。那么还有一点值得注意的是，困境反转逻辑，比如消费领域出现困境反转的信号，虽然生猪养殖依旧低迷，但是种植业已经出现了回暖，这些方向虽然现在还没有起势，但是后续需要我们持续的进行回升。最后我们要注意的是，业绩好不代表股价就一定跟着涨。比如江波龙、兆易创新这些存储的龙头在披露了业绩预高后，反而冲高回落。再比如，像天赐这些锂电股，同样出现利好即下跌的现象，因为市场交易的不是现在，而是预期，甚至是预期的预期。我们看到的数据呢是过去的，但是股价反映的是未来，当业绩已经好到了极致，大家反而担心业绩还能不能更好，还会担心会不会已经见顶了，比如存储芯片会不会再次供过于求？这就是为什么有些公司的业绩虽然那么强，但是股价却开始下跌的原因。所以业绩要和位置结合在一起去看。如果位置已经到了很高，那业绩再好也可能是利好出现。那么如果位置还在低位，那业绩超预期可能才是真的机会。
