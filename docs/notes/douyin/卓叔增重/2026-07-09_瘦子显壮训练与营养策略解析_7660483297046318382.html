一句话结论 本文以“子豪”百天增肌案例为引，指出力量增长是肌肉显壮的底层逻辑。针对瘦子群体，提出三大核心要点：采用线性加重降容量的训练策略避免凭感觉训练；通过科学补充肌酸（每日2-3克）与碳水化合物（每日4-6克/公斤）提升磷酸原与糖酵解系统能量储备；强调高容量训练（单动作总次数30-40次以上，6RM以上力竭）以促进肌浆肥大而非单纯追求神经募集的力量举模式。

（二）核心内容

  2. 线性训练策略应用 摒弃“看状态凭感觉”的盲目训练，采用逐步增加负重并适当降低容量的线性策略。初期高容量建立动作记忆，后续循环加重、缓冲疲劳与减载恢复，适合新手突破力量瓶颈。

  3. 能量系统与营养补充 磷酸原系统依赖肌酸储备，建议新手每日摄入2-3克肌酸粉避免腹泻风险；糖酵解系统依赖肌糖原，需重视训练前后碳水补充及每日每公斤体重4-6克的总摄入量，以维持高强度训练体力。

  4. 训练容量与肌肉维度 单纯追求低次数大重量易导致力量大但维度小。瘦子增肌应注重代谢压力与肌浆肥大，每个主要动作总容量控制在30-40次以上，多组数接近力竭（6RM以上），避免仅采用力量举式的极低容量训练。

1. 引言与力量监控逻辑

这位细狗的名字叫子豪，这是他增肌一百天的变化，看着还可以吧。但如果我们把周期缩短成一个星期，你从外形上几乎看不出它有任何变化，这也是很多新手增肌的一个难点。锻炼完肌肉充血了，看着转了一圈还挺自信，那不到半小时就大为圆形，根本就不知道这是训练到底有没有效果。是这样吧，那你肯定想知道我们是怎么量化子豪的进步速度，让它短时间内这么显壮的。这个诀窍就是监控它的力量水平，力量水平和两个因素呈正相关。一个是神经募集能力，一个是肌原纤维的发达程度，也就是我们常说的肌肉量。只要你的力量水平在持续增长，神经和肌肉就一定有在进步。我们子豪刚开始连标准的空杆都推不动，而现在它卧推可以用五十公斤做四组八次，深蹲可以用六十公斤做五组十次，这才是它变壮了这么多的底层逻辑。

2. 线性训练策略详解

那么作为一个体能特别差的瘦子，怎么才能像子豪一样突破力量尽快显壮呢？这里给大家总结了三个要点。第一，要使用线性策略。如果你今天用四十五公斤深蹲，请问下次深蹲你要用多少公斤？大部分人是没有想过这个问题的，而是根据这六个字看状态、凭感觉。状态很好，就考虑加点重量；感觉加不上，就随便拿个重量拼命练，反正练到力竭了，肌肉酸痛的不行了，应该就练到位了。都被我说中了没有？这就是你的力量和肌肉都长得慢的原因。我们给子豪的线性策略是这个样子的。第一次深蹲用十公斤做五组十五次，因为子豪起点特别低啊，所以用的是这种十公斤的女生专用杆，五组十五次这么高的容量，可以帮它形成肌肉记忆，尽快的把动作给学会。第二次深蹲十二点五公斤，第三次深蹲十五公斤，第四次深蹲他动作掌握的很好了，所以直接上到二十公斤的标准杠铃杆，并且开始降低容量，做四组十四次。第五次二十五公斤，四组十三次；第六次三十公斤，四组十二次。一直这么加重量降容量，在三十五公斤的时候他有点抵不住，给他缓了缓没加，但是把容量多加了一两组。在四十公斤的时候疲劳积累的比较严重了，给它减载了一次。休息后状态很好，回来发现可以直接完成四组十二次，就在这个强度开始继续给他线性加重。思路都看明白了吗？尽可能每次或者每周都增加负重，同时降低一点点容量作为缓冲。感觉加不动了就保持重量增加容量，磨一磨疲劳了就减载，然后继续加重量降容量。这就是特别适合新手的线性策略，不是让你照抄这份计划啊，你不一定能像子豪那样加的这么快，毕竟我们是有专业团队的，但是这个思路一定要掌握起来，一定不能在看状态凭感觉。

3. 能量储备与营养补充

第二，要提升能量储备。你要走线性策略，对营养的摄入是有要求的，因为推起重量需要充足的能量。请问这些能量从哪里来？首先开始供能的是磷酸原系统，也就是肌肉里的磷酸肌酸的储备。它可以提升ATP的合成速度，主要负责短时间高强度的运动。就是你能推起多重，四十公斤还是五十公斤，跟它的关系就很大。那怎么增加磷酸肌酸的储备量？主要就是靠肌酸。肌酸是一种天然营养物质，红肉里就富含肌酸，特别是牛肉，更被称为肌酸之王。但是这种称号呢你听听就算了，因为每公斤牛肉的技术含量大概就只有四点五克。对，每公斤啊大哥，这谁吃得下呀？所以大部分老铁都会直接吃肌酸粉，这也是明确对增肌有用的补剂之一。那么肌酸怎么喝呢？有些肌酸教程会分冲击期和维持期。冲击期每天喝够二十克肌酸连续七天，目的是迅速的填满肌酸储备。但我不太建议新手这么喝，因为这么大量的肌酸会吸收大量的水分进入肠道，特别容易拉肚子。所以起步阶段咱们悠着点来，按照每天每公斤体重摄入零点零三克的肌酸，也就是每天吃个两到三克，就能够长期维持磷酸肌酸吃的充足了。等一个月之后训练量上来了，再根据自己的耐受情况考虑要不要加量。在磷酸原之后启动的是糖酵解功能系统，使用的是肌肉里的肌糖原，肌糖原越多，做主的能力就越强，体力就越好。那肌糖原从哪里来？从碳水化合物转换而来，所以健身的老铁都很强调碳水的补充。低碳减脂的人会明显感觉到训练没力气。碳水怎么补充？第一，训练前的十五分钟吃点香蕉面包稍微补充一点，免得待会体力不够用了。第二，训练后三十分钟内安排大量的碳水，直接正餐吃两碗米饭，或者像子豪这样喝两勺增重粉都没有问题。因为肌糖原在训练中被大量消耗了，需要尽快给补上，糖原也是会超量恢复的，越储备越多的。第三，每天的总碳水摄入不能太少。增肌者每天每公斤体重最好吃够四克以上，瘦子群体要吃够六克以上，糖酵解基本就不缺能量了。

4. 训练容量与增肌要点

好，那么还有最后一个要点没讲，就是要确保训练容量提升力量。对瘦子显壮很重要，但你不能只提升力量，否则很容易像部分力量举选手那样，力量它真的很大，但看着真的不太显壮。这种现象呢通常是因为他们的训练计划强度太大，但容量太低导致的。就是经常使用低于6RM的极大重量训练，而且总组数也偏低。这么练可以最大程度的开发神经募集能力以及刺激力量的来源，肌原纤维的增长。但是肌原纤维的尺寸也是比较小的，让肌肉显大的主要是包裹着肌原纤维的肌浆。健美运动员就非常注重肌浆的增长，所以他们主要使用代谢压力练法。针对同一块肌肉的训练容量非常大，而且经常练到力竭。因此你也会观察到这两种极端的人群，肌肉维度和力量大小并不成正比。作为一个想要尽快增肌的新手，特别是瘦子群体，你记住这一点好了，就是每一个主要动作总出现量在三四十次以上。卧推三组十二次、四组十次、五组八次都没有问题，不用太严格，尽量要力竭的次数在6RM以上，多做几组都能达到这个要求。但你要是只练五组五次、三组三次、四组二次，这种主攻力量的练法力量可能会长得更快哦，但是肌肉也许就比较难显壮了。Ok以上就是子豪这一百天的增重训练技巧，如果觉得有帮助求三连求关注，我们下期再见。
