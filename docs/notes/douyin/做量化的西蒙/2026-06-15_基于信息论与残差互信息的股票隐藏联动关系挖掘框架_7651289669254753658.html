  2. 数据处理与基础指标计算 首先将价格转换为对数收益率（RT = log(Pt/Pt-1)），因其具备可加性且适合统计建模。随后计算股票间的皮尔逊相关系数，并将其转化为距离度量（Distance = 2 * sqrt(1 - rho^2)），以便构建网络图的基础拓扑结构。

  4. 残差互信息（Delta MI）的核心逻辑 核心创新在于计算“残差互信息”。先通过高斯基准公式计算由线性相关系数预期的互信息量，再用实际计算的互信息减去该基准值。得到的Delta MI剔除了普通同涨同跌的影响，专门捕捉由共同题材、资金链、商品链或极端行情驱动的隐藏非线性联动。

1. 引言：超越传统相关性的研究动机

今天讲一个我最近在研究的东西，它不是传统的动量因子，也不是简单的反转策略，更不是看一眼资金流就下结论。它研究的是一个更底层的问题：股票与股票之间到底有没有隐藏关系？很多人看股票联动，只会看相关系数，比如两只股票经常一起涨，一起跌，这就说它们相关性强。但问题是，市场里很多真正有价值的关系，根本不是简单的同涨同跌。有些股票平时看起来没关系，但是只要煤炭涨价，他们会一起动；只要某个题材启动，他们会一起被资金拉；只要市场进入极端行情，他们就会一起暴跌。这种关系用普通相关系数经常看不出来。所以我最近搭了一套框架，用信息论给股市画一张X光图，把每只股票看成一个点，把股票与股票之间的隐藏共动关系看成一条线，最后形成一张股价信息网络。这张关系不是为了今天就告诉你明天买什么，而是为了回答一个更重要的问题：哪些股票之间存在传统行业分类和普通相关系数都解释不了的隐藏联动？

2. 第一步：对数收益率与线性距离计算

第一步，我们要把价格变成收益率，公式是 RT = log(Pt / Pt-1)。这里的 Pt 是今天的价格，Pt-1 是昨天的价格，log 是自然对数。大白话就是今天价格除以昨天价格再取对数。比如一只股票昨天十元，今天十点五元，那么就是四点八八 percent 的收益率。为什么不用普通涨跌幅？因为对数收益率在数学上更好处理，多个时间段可以直接相加，更适合做统计建模。第二步，我们算两只股票的相关系数，公式是 rho(i,j) = Cov(Ri, Rj) / (sigma_i * sigma_j)。这个公式看起来复杂，其实很简单，它就是在问股票 i 和股票 j 的收益率是不是经常一起动？如果 rho 等于一，说明他们几乎同涨同跌；如果 rho 等于零，说明线性上没什么关系；如果等于负一，说明一直涨另一只跌。但是相关系数有一个很大的问题，它只能看线性关系，比如 A 涨百分之一，B 大概涨百分之零点八，这种关系它能看出来。但如果 A 和 B 平时不怎么相关，只有在极端行情、题材行情、商品行情、理财一起动，普通相关系数可能根本就抓不住。为了把股票关系化成网络，我们还要把相关系数变成距离。公式是 Distance(i,j) = 2 * sqrt(1 - rho^2)。这个公式的作用是把关系强弱变成距离远近。如果两只股票相关系数是一，那么它的 distance 就等于零，说明他们非常近；如果相关系数是零，那么 d 就约等于一点四一四，说明关系一般；如果相关系数是负一，那么 d 就约等于二，说明距离最远。所以这个公式做的事情就是相关性越高，距离越近；相关性越低，距离越远。这样我们可以把股票化成一张网络图。

3. 第二步：互信息与自适应分箱

到这里还不够。因为相关系数只看线性关系，我真正想看的是线性关系以外的隐藏关系。这里就要用到一个更关键的概念：互信息（Mutual Information）。公式就是互信息等于 sum(P_uv * log(P_uv / (P_u * P_v)))。这个公式不要死记，直接用大白话理解互信息：问的是，如果我知道股票 A 今天处于什么状态，能不能帮助我判断股票 B 今天处于什么状态？如果不能，说明 A 和 B 没有信息关系，互信息接近于零。如果能，说明 A 的走势里包含了 B 的信息，互信息就会变大。举个例子，我们把股票每天收益分成几大类：大跌、下跌、震荡、上涨、大涨。如果 A 大涨的时候，B 大涨的概率明显变高，A 大跌的时候，B 大跌的概率也明显变高，说明 A 和 B 有信息联动，哪怕他们平时相关系数不高，互信息也可能很高。这就是互信息比相关系数更强的地方：相关系数看的是当下的同涨同跌，互信息看的是信息依赖。那互信息怎么计算呢？一个比较稳的方法叫自适应分箱，公式是 B = max(3, n^(1/3)) 的最大数。这里的 n 是样本数量，B 是分箱数量。比如我们用过去三百天数据，那三百的三分之一次方约等于六点七，上下取整就是六。所以我们大概把收益率分成六个箱子，你可以理解成极弱、偏弱、中性、偏强、极强，再加一些中间层。然后我们统计 A 落在某个箱子时，B 落在某个箱子的概率。如果他们完全独立，那么联合概率应该等于各自概率相乘，P_uv = P_u * P_v。如果实际的 P_uv 明显偏离这个结果，这说明两只股票之间有信息关系。所以互信息的核心不是看涨跌幅大小，而是看两只股票的状态分布是不是互相影响。这里我更倾向用自适应分箱，而不是一上来就用更复杂的 KNN 互信息，因为 A 股和 Crypto 的噪声都很大，太敏感的方法容易把噪声当成信号。

4. 核心步骤：高斯基准与残差互信息

但这里还有一个问题，如果两只股票相关系数本来就很高，那互信息自然也会高。比如银行股之间、煤炭股之间、白酒股之间本来就容易一启动。那我们不能看到互信息高，就说发现了隐藏关系，因为这可能只是普通线性相关带来的。所以这里要用到更重要的公式，这个叫高斯基准互信息。公式等于 -1/2 * log(1 - rho^2)。大白话就是：如果两只股票只是普通线性关系，那么在这个相关系数下，他们理论上应该有多少互信息？然后我们再算一个残差公式如下，这个才是核心：Delta MI = 实际互信息 - 高斯基准互信息。换句话说，剥掉普通同涨同跌之后，这两只股票之间还剩下多少隐藏联动。举个具体例子，假设股票 A 和股票 B 的相关系数是零点六，那么高斯基准互信息是 -0.5 * log(1 - 0.6^2)，约等于零点二二三。这代表什么？代表如果 A 和 B 只是普通线性关系，那他们有零点二二三的互信息是正常的。现在我用真实数据算出来 MI = 零点三五，那么残差互信息就是零点三五减去零点二二三，等于零点一二七。这个零点一二七就很关键。他说明 A 和 B 之间不只是普通同涨同跌，他们还有额外的隐藏共动，可能是同一个商品价格驱动，可能是同一个题材、资金驱动，可能是同一个产业链冲击，也可能是极端行情里的尾部联动。所以这个框架的核心不是相关系数，而是残差互信息。如果 Delta MI 接近零，说明这两只股票的关系基本被普通相关系数解释完了。如果 Delta MI 长期大于零，说明这两只股票背后可能有非线性的关系，比如题材链条、资金链条、商品链条、流动性链条。

5. 网络可视化：MST 与 PMFG

那这个东西怎么变成一张股票网络？我们先计算所有股票两两之间的 Delta MI。如果有一百只股票，就一百乘以九十九除以二，等于四千九百五十，也就是四千九百五十对股票关系。然后我们把 Delta MI 高的股票连接起来，一只股票是一个点，两只股票之间隐藏联动越强，线就越粗。最后我们会看到一张股票关系网。这张网可能会告诉你很多有意思的东西：有些股票虽然不在同一个行业，但它们会聚在一起；有些股票虽然行业相同，但隐藏联动并不强；有些股票可能是某个题材网络里的核心节点；有些股票可能是非线性风险暴露特别高的股票。这里面还有两个图过滤方法。第一个叫 MST（最小生成树）。他的逻辑是在保证所有股票被连接起来的前提下，只保留最核心的 N-1 条边。如果有一百只股票，MST 只保留九十九条边。它很干净，很像市场的主干股价，适合看传统行业结构、市场主线、核心板块关系。但他也有缺点：边太少，会丢掉很多局部题材结果。第二个叫 PMFG（平面最大化过滤图），它最多保留 3N-6 条边。如果有一百只股票，3*100-6=294，也就是最多保留二百九十四条边。PMFG 比 MST 保留的信息更多，他可以看到小团体、小圈子、局部抱团，比如几个煤炭股形成一个小团，几个算力股形成一个小团，几个机器人概念形成一个小图。所以，我的理解是，MST 更适合看市场股价，PMFG 更适合看隐藏团伙。

6. 因子化应用与实战流程

如果只是两两配对，它还不够，最好接入选股框架。所以我会把它升级为个股因子，公式就是 Delta MI 的均值 = 1/(N-1) * sum(Delta MI_ij)，当 j 不等于 i。什么意思呢？对股票 i 来说，我计算它和市场上其他所有股票的平均残差互信息。如果这个值很高，说明这只股票和很多股票之间都有线性相关解释不了的隐藏联动，这可能代表他是题材核心股，可能是产业链核心股，可能是资金共振中心，也可能是拥挤交易里的高风险股票。所以这个因子不一定是直接买入因子，它更像一个非线性共动暴露因子，它可以用来做三件事：第一，找题材核心节点。如果一只股票和很多同题材股票的 Delta MI 都很高，它可能不是普通跟涨股，而是这个题材网络里的关键节点。第二，做风险中性化。如果你的策略本来就暴露在某个题材上，你可以控制 Delta MI 的平均值，避免组合过度拥挤。第三，做配对交易候选池。如果两只股票长期 Delta MI 都很高，但短期价差偏离，可以拿去做进一步的协整验证和均值回复测试。注意是候选池，不是直接开仓。最后讲一下怎么实现：第一步准备数据，你只需要日频收盘价，可以用 A 股，可以用 Crypto。第二步计算对数收益率。第三步设定滚动窗口，比如过去三百天，每隔二十天或者二十五天滚动一次。第四步，对每个窗口里所有的股票，两两计算 Pearson 相关系数。第五步，用自适应分箱计算互信息。第六步，计算高斯基准互信息。第七步，得到残差互信息。第八步，把每只股票和其他股票的 Delta MI 做平均。第九步，拿这个因子去做单因子测试，看 IC、Rank IC、分组收益、换手率、最大回撤。如果最高组和最低组收益差明显，说明他可能有 Alpha 或风险暴露价值。如果收益不明显，但它能降低组合回撤，说明它更适合做风险因子。最后总结一下：普通相关系数看的是股票之间有没有同涨同跌，互信息看的是股票之间有没有信息依赖，残差互信息看的是剥掉普通相关以后还有没有隐藏联动。所以，这套框架真正研究的不是涨跌预测，而是市场结构。他想回答的问题是，哪些股票表面上不相关，但背后被同一条资金链、题材链、商品链、情绪链连接在一起。在 A 股它可以用来研究题材轮动，在组合管理里，它可以用来识别拥挤风险，在因子研究里，它可以改造成一个非线性共动暴露因子。一句话，相关系数只能看到市场表面的同涨同跌，而残差互信息看到的是市场背后的隐藏共振。我是做量化的，西蒙，关注我，收看更多前沿量化研究技巧与知识。（本视频仅供参考，不构成投资建议）
