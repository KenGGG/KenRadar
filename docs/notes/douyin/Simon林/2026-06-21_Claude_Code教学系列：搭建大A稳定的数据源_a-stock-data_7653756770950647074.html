一、内容简述

（一）一句话结论

一句话结论 视频介绍了名为 a-stock-data 的开源项目（已获5千Star），该项目旨在为大模型Agent提供稳定、全面的中国A股市场数据源。作者详细解析了该项目的七层数据结构（行情、研报、信号、资金、基本面、技术、公告）及二十八个API端口，涵盖实时行情、K线、研报、龙虎榜、主力资金等数据，并说明了从依赖AKShare到直连接口的版本迭代优化。

（二）核心内容

  1. 项目概述与核心优势 介绍开源项目 a-stock-data 已获得5千Star，经过多次版本迭代。相比同类数据库，该项目吸收了多个仓库的优点，能够拉取实时行情、五档盘口、分钟级K线、机构及个股/行业研报、龙虎榜等数据，功能全面。

  2. 行情层面数据接口 主要使用通达信接口，支持全周期K线（含1分钟K线，可回溯5个月，日K线可追溯至上市首日）。腾讯财经作为补充，提供PE/PB、总市值、换手率、涨跌停等数据。百度接口用于K线均线数据。此外还支持通达信实时行情。

  3. 研报与信号层面数据 研报通过东方财富接口获取，新版增加了行业研报接口（区别于个股研报）。还整合了同花顺机构预期、艾文财语音搜索等功能。信号层面包括强势题材、热点原因分析、同花顺数据以及通过东财接口获取的龙虎榜数据。

  4. 资金面与基本面数据 资金层面涵盖主力筹码、主力资金、融资融券、大宗交易、筹码分布及分红数据，主要依赖东财接口（虽有部分限制但已配备相应数据）。基本面资讯包括财务快照、财务报表、新闻资讯及巨潮全量公告，接口均已配齐。

  5. 版本迭代与Agent集成指南 V3.0版本砍掉了AKShare依赖，改为全部直连端口，并进行了一系列优化。目前项目包含七层数据、二十八个端口。用户可将仓库告知AI Agent，由Agent根据需求自行决定抓取哪些数据及存储位置，实现自动化数据获取。
