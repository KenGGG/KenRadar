一、内容简述

（一）一句话结论

一句话结论 作者基于原版TradingAgents（65K Star）仓库，针对A股市场特性进行了深度改造，命名为TradingAgents-AStock。主要改进包括：新增政策分析、游资追踪（龙虎榜）、解禁监控等A股特色角色；接入S-Lock Data直连数据源（K线、PE、新闻等）；增加报告质量门控自动检查机制；提供Web UI支持12阶段推演及PDF导出。项目全开。

（二）核心内容

  1. 改造背景与痛点 原版框架存在三个不适合A股的问题：一是数据不通（原版依赖Yahoo Finance，无法获取A股数据）；二是交易规则不符（原版为T+0，A股为T+1且有其他限制）；三是角色缺失（原版仅4个角色，缺乏对政策面和游资的解读）。

  2. 核心功能改造

    1. 角色增强：在原有技术、舆情、新闻、基本面基础上，新增政策分析（产业政策/监管）、游资追踪（龙虎榜/大单）、解禁监控（大股东解禁）。2. 流程优化：增加质量门控，对7位分析师的报告进行自动质量检查，不合格则打回重写，确保辩论基础。3. 数据接入：整合S-Lock Data，直连K线、市盈率、新闻、线上财经等数据。

  3. 系统架构与输出 决策链路分为四层：第一层为7位分析师出具报告；第二层为投研辩论；第三层为风控辩论（激进/保守/中立）；第四层为最终决策。新增Web UI界面，支持输入股票代码后执行12阶段推演，并生成完整报告及PDF导出。

  4. 项目特性与声明 项目名为TradingAgents-AStock，全开源免费，无API Key限制（注：原文提到“没有APK”可能指无需付费API或特定密钥，但建议用户自行配置模型API）。强调内容为AI编程技术分享，不构成投资建议，股市有风险需谨慎。

2. 原版框架的三大问题

原版的框架有三个不太适合的问题。首先是数据是不通的，它走的是Yahoo Finance，A股的数据是拿不到的。第二个是规则，它还是T+0，没有我们大A的规则。然后第三个是角色的缺失，就是它只有四个角色，它缺乏我们对大A的政策面，还有游资之类的解读。所以我对这三个维度进行了深入改造。

3. 角色层面的改造

首先是角色层面，原版Agent有四个角色：技术、舆情分析、新闻、基本面。我增加了政策分析，就是我们大A的一些产业政策、监管政策；还有游资的追踪，就是龙虎榜、大单这些；还有解禁的监控，就是大股东解禁。这些是做了一些A股特色化的新增，增加了这三个角色。

4. 决策链路与质量门控

决策的链路我没有进行改造，还是七个分析师出报告。但是我加了一个质量门控的自动检查，就是对其余分析师的报告进行一个质量的检查。因为原版的这个产品，它出了四个报告之后就没有人检查的，然后就直接到辩论了。但我觉得报告的质量是下面辩论的基础。所以我就加了一个质量检查的环节，如果质量不过关，就打回去让他们重新写。

5. 数据源更新与能力展示

我对这个数据源也进行了更新。大家都知道我的那个S-Lock Data的数据源，我都把它给接进去了。就是数据都是直连的，包括这个K线、市盈率这些，还有新闻、线上财经这些都连进去了。能力方面就是开箱即用，大家把这个TradingAgents-AStock给到你的Agent，它就会用了。然后七个分析师有七个数据源，还有五档的评分。

6. Web UI与总结
