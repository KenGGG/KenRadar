一、内容简述

（一）一句话结论

一句话结论 本集演示如何利用Claude Code自动化拉取并分析行业研报，以填充投研看板框架。重点分享了通过修改API参数（qtype=1）批量获取行业研报的方法，并结合i问财提升效率。强调需使用高性能模型阅读研报，以准确提取环节定位、技术/产能壁垒及竞争格局等关键信息，避免低质模型导致的分析偏差。

（二）核心内容

  1. 研报拉取方法与API技巧 通过向Claude Code发送指令，利用Astock Data接口拉取最近三个月的行业研报。关键技巧是将接口参数qtype从默认的0（个股）设置为1（行业），以获取批量行业研报。建议每个子行业拉取不少于300份，或指定特定时间段（如2026年）的最新研报。

  2. 多源数据协同与效率优化 除了Astock Data，建议同时研究并使用i问财接口，两者结合可提高数据拉取的效率和数量。i问财接口需要特定的Key，用户可自行研究配置。

  3. 研报阅读与分析框架填充 拉取研报后，需使用“聪明”的高性能模型进行阅读和分析，避免使用低质模型导致结论偏差。分析内容包括环节定位（如谐波减速器）、壁垒类型（科技壁垒或产能壁垒）、国内外竞争格局等，并将结果填入投研看板的各个细分环节。

  4. 方法论通用性与后续扩展 该投研方法论适用于人型机器人、AI算力等多个产业。用户可将此流程作为独立页面或模块，通过调整Prompt让Claude Code增加新功能（如全球温度计）。核心在于使用高Token消耗的高质量模型以确保分析深度和准确性。
