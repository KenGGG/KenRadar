2. 银行股上涨的资金机制

我们都知道，四大行都是上万亿的市值巨无霸，按理说拉动它们上涨，是不是需要天量资金来买入的？其实，拉动银行并不需要多少资金，只需要少量的增量资金即可。这里辉哥借助一下拍卖会的例子，一件拍品，比如一个股票的最终成交价，并不是由在场所有人的财富总额决定的，而是由愿意出最高价的一位买家来决定的，它的出价行为决定了这件拍品此刻的市场价值。那么银行股持有者并没有大量抛售股票，虽然市值是一万亿，但假设其中只有一亿的市值的股票摆在市场，只需要出一亿资金就可以拉动股价上涨，并不需要出剩下的九千九百九十九亿元了。现在买入银行股的也都是不差钱的长线资金，正是因为这些长线资金造就了A股银行的大牛市。

3. 保险资金成为最大推手

保险资金就是银行股上涨的最大推手之一了。这几年，随着增额寿和年金险变得火爆，保险公司完成了不少年化百分之二点五到三点五的保单。过往保险公司能称作债券、非标资产能够轻松跑赢资金成本。但现在十年期国债到期收益率跌到了百分之一点六五的水平，那么再想轻松跑赢就比较困难了。因此，监管层决定放开保险公司对投资资本市场的限制，以便他们寻找能覆盖资金成本的方式，而保险资金天然就是长线资金，对A股来说是利大于弊的。目前，中证银行指数的股息率为百分之五点六，是远远能跑赢保险公司的资金成本的。而自23年起上市险企全面执行IFRS9准则，其中金融资产可以通过FVOCI账户来买。简单来说，就是可以把买入股票后获得的利息当做公司的利润表，而股价本身的波动则计入资产负债表。这样做的好处在于，保险公司的股价不会被短期的投资业绩所影响，而会因为股息的收入增加，让利润表更好看。

4. 被动资金与主动基金的推动

第二个是被动资金的买入，这是23年以来最重要的一股力量。中央汇金通过买入ETF来构建A股的底部，大量的钱通过购买沪深300ETF、上证50的方式流入A股。基金经理拿到钱必须按照权重来买股票，银行在指数里就是一个巨无霸，那么大量的钱自然就被动地流入了银行股。并且，央行在5月表态，汇金将得到无限量的支持，用于股市维稳。第三个是主动基金抱团，这一点是最令人玩味，也最无奈的。过去几年，主动型基金经理们瞧不上银行，嫌它太慢，去追逐各种景气度、成长性，各种梭哈赛道，赌对了我是冠军，赌错了，我换个产品或者换个公司再来。因此，监管层发布了公募基金新规，明确了基金经理的薪酬是与业绩挂钩的，而业绩则需要和业绩基准挂钩。因此，过往那些基金经理不得不选择大规模调仓，以确保组合和业绩基准的偏离度不要太高。根据财通证券的测算，假设主动基金全部按照业绩基准调仓，则银行将会成为资金流入最多的板块，这是未来银行股存在系统性行情的可能性之一。
