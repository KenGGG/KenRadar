（二）核心内容

  1. 完善个人资料与记忆提取 在设置的个人资料部分填写详细的工作流程、工具和习惯。建议利用第三方工具（如 Memory Setcom）从 ChatGPT 或 Gemini 迁移历史记忆，或直接让 Claude 通过问答形式生成自定义指令。

  2. 启用跨会话记忆功能 在设置的能力选项中开启记忆功能（免费用户可用），使 Claude 能在不同对话中记住用户的工作偏好和项目信息，提升交互的个性化程度。

  3. 创建自定义写作风格 在主聊天框左下角点击加号，选择‘使用风格’并创建新风格。通过粘贴电子邮件、LinkedIn 帖子或博客文章等示例文本，让 Claude 模仿特定的语气和格式进行创作。

  4. 建立项目以隔离上下文 为常规任务或特定项目创建独立空间。项目功能类似于 ChatGPT 的 Projects，允许上传文档并设定专属指令，将特定知识限制在项目内，避免与通用记忆混淆。

  5. 连接外部工具实现自动化 通过左侧菜单的连接器功能，绑定 Google Drive、Gmail、日历、Notion、Asana 等工具。设置权限后，Claude 可直接读取文件、安排会议或执行任务，无需每次手动询问。
