一、内容简述

（一）一句话结论

一句话结论 文章指出投资初期缺乏正反馈是常态，甚至早期盈利可能是危险信号。通过对比短期即时奖励（如打工、游戏）与长期延迟满足（如价值投资），分析了人性中多巴胺机制对投资的负面影响。引用芒格、巴菲特及刘旭等观点，提出应培养“钝感力”以忽略短期波动，专注投资逻辑，并理解“竹子定律”中根系生长的隐蔽性，避免在黎明前放弃。

（二）核心内容

  1. 早期盈利的陷阱与自我认知偏差 投资初期若无正反馈反而是好兆头，早期赚钱易导致过度自信和丧失客观判断，类似庞氏骗局的诱饵。多数投资者高估自身能力，如查理·芒格调研显示80%普通人自认优于芒格，这种心理普遍存在。

  2. 即时反馈与延迟满足的冲突 人类天性偏好短期即时奖励（如小时工、短视频的多巴胺刺激），而投资需要延迟满足。早期投入大、无反馈，如同播种期，看似无进展实则根系在地下生长。

  3. 竹子定律与长期主义 引用“竹子定律”，前四年仅长几厘米，实则在扩展根系，第五年爆发式增长。投资同理，若因短期无收益而频繁切换策略或放弃，将错失长期复利。

  4. 应对策略：钝感力与平常心 建议培养对短期波动的“钝感力”和对投资逻辑的“锐感力”。参考基金经理刘旭观点，不因错过机会而焦虑，像种树不拔根查看。巴菲特强调无需过高智商，避免过度分析干扰持仓。应以三至五年为周期评估表现。

1. 投资初期的正反馈悖论

投资在开始的阶段呢是不会有正反馈的。因为任何在后期有巨大收益的事儿，在前期都是没有反馈的。比如我们创业的前两年，那营收很可能就盖不过成本。再比如说现在的这个自媒体，对我们前一百条的视频很可能也没有任何人看。投资的前三年很可能亏亏过几次的钱。因为投资这个事儿，反而一开始你就赚钱了，不是好的预兆？因为投资最怕的就是盈利，一旦你上来就赚钱，你就会把这个当成是一种即时反馈的毒簿。那一旦着相了，往往就是灾难的开始。因为你会对行情深信不疑，才失去了客观的判断，任何上涨和下跌都会给你造成心态上的影响。就跟赌场赌红眼一样，赌场想让我们倾家荡产，一定是想让我们先赚到钱，就和庞氏骗局一个道理，一开始都要让我们吃到肉，只有吃到肉了，玩家才会疯狂，才会认为无所不能，才能让我倾向荡一知。

2. 过度自信与心理偏差

今天看到投资家路路一个演讲，他说他当时呢和查理·芒格做了一个调研，具体是在华尔街还是这个杂志上，我记不太清楚了，知道的粉丝可以在评论区打出来。结果呢这个调查非常有意思。在受试者中，百分之八十的普通人都认为自己能在投资上取得比查理·芒格要好的成绩。因为芒格的年化其实比巴菲特还要低一些。比如我们让大V的一些短线玩家看了，那他就觉得哎这一年十几个点二十个点，那我随便凹几个涨停板就能比你强了。所以就是这种心态，我们每个人都有极度高估自己的倾向。同样的，之前网上不还是有一个驾驶能力的调查，结果也大部分普通人都认为自己驾驶能力要远高于平均水平，认为自己比别人更强。但这个心理属性呢在男性群体中非常明显。进入这个市场中的第一天，但觉得自己能赚到大钱。但投资的开始阶段往往是一段高开低走，或者是低开低走，或者是平开低走。最后在慢慢的盈利过程，最也是投资前期沉没成本巨大，没有正反馈的一个特点。反而那些一开始正反馈就特别强的事，最后往往赚不到什么大钱。比如干小时工确定性非常强，一个小时三十块，我们干一小时就一小时的钱。在麦当劳炸薯条也有正反馈，炸一小时的薯条就能赚一个小时的钱。但这些开始就有正反馈的事儿，往往没有多少向上的空间。

3. 多巴胺机制与延迟满足

但我们的人性天生就喜欢短期的正反馈，因为人类的DNA中喜欢的就是即时奖励，而投资恰恰看的是延迟满足的能力。如果在二零一九年买入茅台，后面的两年时间收益会翻倍。但从二零一二到二零一四年，茅台曾经连续下跌超过百分之五十。在这个期间，无数的投资者选择了割肉离场。在当时呢很多人也骂白酒是泡沫，也嘲笑价值投资在大势是无效的，但最终留下的人享受了后面十年，就是一直到二一年近十倍的回报。那投资最痛苦的阶段呢，就是在看不到希望的阶段。因为亏损了至少还有负的反馈。最可怕的呢就是钝刀子割肉式的亏损。每天打开账户虽然亏的不多，但一年过去、两年过去就会开始怀疑最初的方法，然后呢开始修改切换策略，再开始不断的追其他的热点，更换其他的菜刀。因为我们人类大脑的设计天生就不适合投资。现代神经科学发现，人类在大脑奖励系统主要依赖的是多巴胺。很多人以为这个多巴胺来自是获得奖励，但其实真正刺激多巴胺分泌的是即将获得奖励的预期。什么意思呢？就是我们打游戏为什么上瘾？刷短视频？为什么上瘾？因为这些事情会不断的给我们即时反馈，就比如我们现在正在看的这个短视频，你每点一下都会释放大脑分泌多巴胺，这就形成了正反馈循环。但投资呢恰恰相反，投资就像我们那个农村种庄稼的播种阶段，而不是那种收获的阶段。播种的时候呢最累。虽然看起来这个地种完了，庄稼毫无变化，但地下正在生长根系。很多人以为自己几年下来没有进步，其实只是这个根生长在了地下，只是现在看不到。

4. 竹子定律与古文哲理

而《道德经》中强调合抱之木，生于毫末；九层之台，起于累土；千里之行，始于足下。什么意思呢？就是所有巨大的成果，最开始都是微不足道的，但最关键的成长阶段往往是看不见的。《周易》中说，潜龙勿用，什么意思呢？就是龙已经存在，只是还在水下还没到起飞的时候。所以古人讲，势未至，不可躁进；事未成，不可妄动。毛竹在前四年就是竹子在前期几乎看不见它的生长，每年呢只长几厘米。很多人以为呢这竹子就死了，但从第五年开始，短短六周时间就能长高二十几米，为什么呢？因为它前四年它一直在地下长根，根系的面积达到了数百平方米，后来才能爆发式的增长，只不过是前面累积的结果，这就是著名的竹子定律。所以很多人投资呢第三年了，一看还不涨，就直接把这个竹子拔了。所以呢他就看不到第四年之后的成果，然后呢可能会抱怨方法没用。

5. 应对策略：钝感力与长期视角

投资家李璐有一句话，他说投资最重要的就是平常心，不需要我们过度的去关注这个涨跌，平常心对待即可，也不能产生焦虑。因为焦虑会让我们提前放弃正确的事儿。比如我们正在持有一个对的筹码，但今天我们看存储涨了，明天看半导体设备涨了，但长此以往，就会出现焦虑的心情。一、焦虑就容易出现错误的决策。那么在没有正反馈的阶段，我们该怎么办呢？那基金经理刘旭之前提到了一种能力叫钝感力，就是不在意市场短期的涨跌，也不用天天盯着这个账户，天天看收益，就像我们种树，我们种着树，却天天的挖根看根。那这棵树呢就永远长不了。他说这个投资的压力来源主要就是错误或或者是错过了好的机会。所以，要成功地穿越的动，需要对市场情绪培养钝感力，对投资逻辑培养锐感力。关注这个比赛的本身不去看积分牌，能让我们更放松，更享受这个比赛的过程。巴菲特有一句话，他说，在投资中，如果你很聪明，有很高的智商，那你想要在投资中赚钱，那你就需要把多出来的智商卖给别人。因为你不需要这么高的智商，你想的越多，分析的越多，就越影响你持仓的判断。最后呢就是去看长期的样本，而不是看一个月看三个月，以三年、五年为一个周期，时间尺度不同，那结论也会不一样。市场中有一句话叫一年三倍者众，三年一倍者寡，尤其在短线中，我们直接all in追涨，靠某一次机会，翻倍的概率非常大。但如果谁能保持长期的稳定盈利，这才是最难的。
