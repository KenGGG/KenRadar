一、内容简述

（一）一句话结论

一句话结论 分享开源项目Agent-Staff，该系统基于飞书搭建，旨在将公司各部门及整体运营Agent化。作者结合前CEO经验，演示了如何通过Agent实现跨部门数据汇总、财务分析、电商运营监控及自动化汇报等功能，强调数据隔离、权限管理及私有化部署优势，能有效提升管理效率并降低人工成本。

（二）核心内容

  1. 项目背景与核心架构 作者曾担任CEO，为解决管理层看不清、管不过来的痛点，开发了Agent-Staff系统并开源。系统设定了9个部门Agent（如短视频、电商、研发、财务等）及1个统筹全局的CEO参谋长Agent。基于飞书搭建，所有数据归公司私有，未进入第三方仓库。

  2. CEO参谋长与跨部门协同 CEO参谋长可穿透查看全公司经营情况，自动调取各业务部门数据进行统计汇总，并提供关键盯防要点。支持深度追问（如拆解业务回款），大幅减少管理层与部门间的沟通摩擦，提升决策效率。

  3. 职能部门Agent应用案例 财务部Agent可汇总营收、支出及固定成本，适配不同公司情况；电商Agent通过分析Listing数据、收入及爆款流量，替代人工Excel分析；短视频Agent提供选题、转粉率及分发效果报告；研发Agent跟踪开源仓库进展。

  4. 自动化汇报与权限隔离 Agent具备主动汇报和提醒功能，可按日/周定点汇报部门情况或跟踪回款进度。系统严格设定‘部门墙’，单体部门Agent仅能访问本部门数据，权限按人控制，确保数据安全与隔离。

  5. 系统集成与持续优化 利用飞书作为底层OA系统，集成考勤、审批、财务文档等功能。例如人力Agent可查看考勤，财务Agent可汇总报销审批。系统支持随公司发展不断迭代优化，沉淀部门数据资产，适合不同业务形态的企业定制。

2. 痛点分析与系统架构

当老板最累的其实就是看不清，也管不过来。因为部门太多了，信息太多了。比如说要看每个部门的数据的时候，就得叫他的部门负责人去汇总。然后这个部门负责人可能还不太清楚，他还要让员工去汇总，所以这是一个比较繁琐的事情啊。我们主要就是解决这个数据的痛点。因为现在有了AI，Agent Staff呢它不是个概念，是我自己在跑的。呃，我设定的九个部门全都是由Agent在里面去负责这个部门的，包括短视频运营、电商啊、投资研究、研发产品、海外社媒。呃，职能线呢就包括财务、人力、行政，然后统筹全局的，还有一个CEO参谋长。

所以他可以去获取各个部门的一些情况跟数据跟报告。然后剩下的单体的部门呢，他们是只能在自己的部门的权限内看自己部门的文件跟数据啊。举个例子，就是CEO参谋长他能够看穿整个公司的情况啊。你看这是我举的例子啊，就是我问这个CEO参谋长，你公司的呃，我们公司整体的经营情况怎么样？然后他就会去调取电商运营，然后业务部自媒体运营与这些所有的部门的数据，然后进行一个统计汇总，还包括这个账务的口径，然后还会给我提示要盯的要点。他是怎么得出这些结论的？是每个部门都有每个部门的啊，对于表格，还有部门的信息，还有汇总的信息，所以他就会去读取啊。然后接下来我会跟他说把业务回款拆开看，然后他就会去研究具体的情况，再来反馈给我。所以他就减少了很多的摩擦，会比较利于CEO啊，包括高管啊去呃有效的管理这些部门啊。

包括财务部，其实也是有Agent的。你就可以直接问他这个月公司进行情况怎么样，他就会去汇总营业的收入，包括营业的支出、固定支出啊，这些财务的情况可以根据呃每个公司的情况进行去适配。然后财务呢是根据每个部门的这些业务数据去调取的。当然也可以做一个财务本身的一个呃有凭证的汇总的一个台账。然后Agent呢他就能非常高效的去调取这些数据，而且你再去问他各种细节，他都能很快的答出来。我这是这个电商部门的，电商部门的Agent呢，它就类似于一个呃辅助。因为它有电商的整体的情况，只要把我们的电商的店铺的Listing的数据，还包括这个收入的数据都告诉他，它就能进行分析。包括谁在啊拉动这个整个店铺的销售，哪个Listing是爆款，它的流量是什么样的，还包括哪个子品，在这个月的时候表现比较好啊，转化比较好。所以这些都能进行统筹的分析。就这个就确实比以前通过人工去拉Excel表格，然后通过多个维度的分析，这个要高效非常非常的多。嗯，所以有这个Agent其实是能比较高效的提升的。

除了CEO用以外，其实也可以让部门的负责人去用啊，这个其实呢是能起到很很好的作用的。然后这还有一些部门，包括短视频的运营部门，他能够呃选题、算你的转粉率啊、分发效果啊，这些都能去通过数据的分析得出比较精准的报告啊。包括这个投资研究的部门啊，能去这个就不多说了啊。包括研发的部门，就比如说能跟踪像我就像会让他跟踪我的开源仓库的整体的进展。然后每个仓库的现在的这个增长的情况，还包括海外社媒，有一些像网站的产品啊，它是需要去发帖去运营的，这个也是能够自动去跑的。但还可以根据呃不同的部门去对不同的需求啊，去设定不同的部门。因为每个公司的情况都不太一样，这个呃核心就是能能做的事情，就是你能够跟他沟通，然后他能够给你反馈一些结果。但除了反馈这些结果之外，他其实还是能够发文件的。他能够调取整个部门的文件以及公司的文件啊，他也能够去对这些文件啊，包括数据进行分析。所以这个是能够非常有效的去取代一定的人工，同时呢也能非常准确的反馈信息。这个确实是比呃一般的刚入门的员工的这个信息准确度跟效率会高非常的多啊。
