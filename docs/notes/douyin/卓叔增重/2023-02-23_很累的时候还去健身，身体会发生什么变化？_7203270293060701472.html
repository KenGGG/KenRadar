1. 运动引发的生理变化

为什么经常运动的人竟然会猝死？要回答这个问题，我们需要先了解运动的时候，我们的身体发生了什么变化。身体发生的第一个变化是血压。运动会导致交感神经变得兴奋，交感神经一兴奋，我们的血压就会急剧上升。如果你做的是中等强度的运动，例如中等速度的跑步，在健身房撸铁等，正常人的血管收缩压可能会从一百二十毫米汞柱上升到一百八十毫米汞柱。如果你做的是高强度的运动，例如HIIT、参加短跑比赛、挑战自己的极限，血管收缩压可能会高达两百毫米汞柱以上。大家可能对这个数字没什么概念。这么说吧，前阵子发布的那个中国高血压临床实践指南，不是把高血压的判断标准下调为一百三十杠八十毫米汞柱嘛，其中前面的这个一百三十就是血管收缩压。这么一对比，哇，运动起来不就妥妥变成高血压了吗？这也太可怕了吧。这个大家倒也不用害怕，因为运动导致的血压上升只是临时性的，运动结束后很快就会恢复，对我们正常人没有什么影响，所以不用担心。身体发生的第二个变化是心率。由于运动时体内会分泌大量的肾上腺素、去甲肾上腺素等激素，我们的心跳会明显加快，大概从平时每分钟六十到一百次的静息心率上升到每分钟一百到一百四十次。如果是高强度运动，大约每分钟一百四十次是很常见的。心率越快，心脏的负荷也就越大，但是也不用担心，这也只是临时性的上升，我们正常人的心脏也顶得住，这么点负荷不会出什么问题。总的来说，身体是不会因为运动带来的这些变化而出现危险的。

2. 疲劳状态下运动的致命风险

但是，这里肯定得有个但是。如果你在身体状态已经很差的时候进行运动，情况就不一样了。这几年很流行九九六嘛，很多上班族长期熬夜，睡眠不足，连续多天加班赶项目，精神已经极度疲惫。在这种状态下，身体里的各种压力激素，例如肾上腺素、皮质醇、去甲肾上腺素都会使身体长期处于应急状态，这就会导致我们的植物神经紊乱、体内电解质系统失衡。这些因素都会影响心脏的电信号传导。不知道大家有没有试过，在严重熬夜加班的时候，突然出现短暂的胸闷、心慌不舒服的感受，这就是心脏电信号出了问题、心跳开始异常的征兆了。熬完这个夜，赶紧去好好睡一觉，那也就算了，身体也能慢慢恢复过来。但如果你在这种状态下，还进行大量高强度的运动呢？刚刚讲过的运动会让你的血压上升、心跳加快，再加上运动时肌肉又需要大量的血液供应，心脏的负荷是非常高的。而你这些天一直在加班，心脏的压力本来就很大了，还要让它进一步在高负荷下继续拼命工作。完了，心脏电信号彻底就乱套了，心脏没有办法按照信号规律跳动，心源性猝死就这么来了。以前总是有人调侃某个互联网公司说内啥和心脏啊，只有一个能够继续跳动，其实并没有瞎说。所以说句不好听的，运动猝死的人都是自己作出来的。资本家都知道偶尔要给员工放放假，他们才能够继续卖力工作。你对待自己的心脏，怎么就不知道让他好好休息呢？如果你曾经误以为运动能够让疲惫的心脏得到放松恢复，那么我希望这篇科普视频能够帮你纠正这种想法，不要再犯和他们同样的错误。如果你身边有这类天天加班都加到吐了，还拼命去运动的人，可以把这篇视频转发给他，稍微劝一劝。

3. 健身的长期益处与超量恢复

跟他强调三点：第一，运动并不能给身体补血条，反而会给身体带来临时性的压力和负担。第二，充分休息的人可以轻松扛得住这些压力，适当的压力反而会让身体变得越来越好。但是缺乏休息本身压力就很大的人，继续运动则会雪上加霜。第三，如果在开始健身运动之前，就已经感觉到状态很差、很疲惫，心理上很不想练了，或者有头疼、眼窝子疼、脑子有爆炸的感觉，有心跳很快或者胸闷气短等现象，那就不要强撑，不要训练。少练一次不会掉肌肉，先回去好好睡个觉，身体舒服了再运动。只能劝大家到这里了，祝大家好人一生平安吧。好，说了这么多问题，那健身运动对身体健康到底有没有好处呢？肯定是有的。健身对健康的好处主要是身体机能的提升，依赖的是超量恢复机制。利用你做力量训练，力气越练越大。以前你换个水都力不从心，同事都觉得你很虚很弱鸡，现在轻轻松松就换上去了，大家都觉得你的体能很好、很健康。又利用你经常长跑、做有氧，心肺功能不断超量恢复，供血和摄氧能力越来越好。以前上个楼梯就气喘吁吁，现在每天追公交都是最快的那一个，大家都会觉得哇，经常运动的人果然很健康哦。又利用你去健身房增肌，肌肉超量恢复，越练越大，体型越来越好看。大家别觉得肌肉中看不中用啊，它是可以对抗衰老的。别人的五十多岁半截身子都快入土了，你看这位名字叫陈传多的，今年五十六岁的中老年人，看着不比在座的各位都年轻。还有今年八十六岁的中老院士，常年健身，体型又好，精神气又足。你说他健康不健康？通过运动让身体机能提升之后，日常生活会变得更轻松、更从容，这些都是健康的表现，也都是有正向意义的。

4. 科学运动建议与休息优先
