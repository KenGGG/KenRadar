一、内容简述

（一）一句话结论

一句话结论 作者基于原版65K Star的TradingAgents仓库，针对A股市场进行了深度改造，命名为Tradingagents-astock。主要改进包括：增加政策分析、游资追踪和解禁监控等A股特色角色；接入Slock Data直连数据源（K线、PE等）；增加报告质量门控检查；提供Web UI及PDF导出功能。项目全开源免费，支持多模型API接入，包含7位分析师。

（二）核心内容

  1. 改造背景与原版缺陷
    原版TradingAgents框架存在三个主要问题：1. 数据不通，依赖Yahoo Finance，无法获取A股数据；2. 规则不符，采用T+0交易逻辑，不适应A股T+1规则；3. 角色缺失，仅4个角色，缺乏对A股政策面、游资等的解读能力。

  2. 角色与功能增强
    在原版4个角色（技术、舆情、新闻、基本面）基础上，新增3个A股特色角色：政策分析（产业政策/监管）、游资追踪（龙虎榜/大单）、解禁监控（大股东解禁）。同时增加质量门控环节，对分析师报告进行自动检查，不合格则退回重写，确保辩论基础质量。

  3. 数据源与决策链路
    数据源升级为直连Slock Data，涵盖K线、市盈率、新闻、线上财经等。决策链路保持7位分析师结构，分为四层：1. 分析报告；2. 投研辩论；3. 风控辩论（激进/保守/中立）；4. 最终决策。

  4. 产品特性与使用方式
    提供Web UI界面，支持输入代码后12阶段推演并导出PDF。支持接入各类模型API，开箱即用。项目全开源、全免费，无API限制（注：作者提及原版可能有APK限制，但此改造版无此限制）。GitHub提供CN版本，前端代码开源。
