1. 学历贬值现象与名校稀缺性

很多人这两年都有一种强烈的感受，学历好像越来越不值钱。了学毕业生越来越多，本科文凭满大街都是硕士，也开始扎堆。二零二五年，中国高校的本届毕业生已经超过了一千两百万，比十年前几乎翻了一倍。可奇怪的是，在学历贬值的同时，另一个现象却越来越明显，名校的含金量反而越来越高。那大厂招聘时，简历的第一关就直接筛掉了。学校、金融、互联网、咨询、投行岗位几乎只看985、211，所以多是清华、北大、复旦和上交。所以很多中产家庭就会困惑，不是说学历已经贬值了嘛，那为什么名校反而越来越值钱？但背后其实是一个典型的经济学逻辑，学历确实在贬值，但名校的价值却在升值，为什么会这样呢？答案就是稀缺。

2. 供给膨胀与顶端稀缺的经济逻辑

百万在看一个简单例子，如果说一天全中国人都有一块钱，那钱就会变得不值钱。但如果只有极少数人拥有钻石，那钻石的价格就会越来越高。学历的逻辑其实和商品完全一样。当大学教育开始大规模普及的时候，普通大学的文凭就不再稀缺了。一九九八年，中国大学扩招，大学生的数量开始指数级的增长。当年全国大学毕业生只有不到一百万人，而到了今天，已经超过了一千二百万人，数量增加了十几倍。但顶级大学的数量却几乎没有任何变化。中国的985大学仍然只有三十九所，清华北大仍然每年只招几千人。也就是说，普通学历在迅速膨胀，而顶级的学历几乎没有扩容，这就是典型的供给膨胀，加顶端稀缺。于是，结果就出现了一个看似矛盾但又十分合理的现象，学历越贬值，名校越值钱。

3. 名校就业数据与企业筛选成本

很多人可能不信，我们来看几个数据。根据麦克斯研究院发布的大学生就业报告，名校学生的就业率、起薪水平、晋升速度几乎全面碾压普通高校。比如在二零二四年的同期中，清华北大毕业生的平均年薪普遍在一点五万到两万元之间，普通本科院校很多毕业生的起薪只有五千到八千，差距接近两到三倍。如果你再往上看，比如金融行业、咨询行业、投行，这个差距会更夸张。很多顶级投行，比如高盛、摩根士丹利，还有咨询业的麦肯锡，中国区新人的学历背景几乎清一色的清华北大、复旦、上交或者海外的常春藤，普通大学的学生几乎很难进入这个圈子。这里面不是所谓的学历歧视，而是企业的一种效率选择。因为在信息不对称的世界里，企业很难判断一个人的真实实力。于是他们就会用学校作为一个筛选信号，简单讲就是一个人的能力很难被直接察觉，但名校就像一个能力标签儿，企业看到这个标签儿，就默认这个人的学习能力、自律能力、认知能力至少在平均水平以上。所以企业不是在招学校，而是通过学校降低筛选成本。换句话说，名校的价值本质上就是筛选的成本。很多企业一年要看几万份简历，如果每个人都认真面试，成本太高了，于是他们就干脆直接砍掉了百分之九十的学校，只留下少数名校。

4. 同辈效应与成长环境优势

有一个朋友在一家头部互联网公司做人力，他曾经跟我说过，如果两个人能力差不多，我们一定会选名校。为什么？因为名校意味着两个东西，第一，学习能力经过了长期的筛选；第二，成长环境和资源更好。如果你在清华读书，身边的人可能都是各省状元或者竞赛的冠军，这种环境会不断拉高一个人的认知水平，和普通大学环境就完全不一样。这就是所谓的同辈效应。你每天和什么样的人在一起，最后就会变成什么样的人。所以很多企业不是在读学历，而是在赌环境塑造出来的人。

5. 教育通胀与校友网络资源

先看第二个逻辑，学历贬值本质上是教育的通货膨胀，就像货币一样，当市场上货币越来越多，钱就会贬值。同样，当市场上本科越来越多，大家就会去卷硕士；硕士越来越多，以后大家就会去选博士，这就是所谓的学历军备竞赛。美国经济学家曾经做过一个统计，美国过去五十年中，大学学历的普及率不断提高，但顶尖大学毕业生的收入优势却在不断扩大。比如哈佛、斯坦福、MIT这些名校的毕业生，在科技和金融行业的收入远远超过了普通大学的毕业生。这说明一个问题，教育虽然在普及，但顶级教育的溢价却在不断扩大。中国其实正在经历同样的过程。过去二十年，中国的高等教育其实经历了一次巨大的扩张，但顶级高校依然非常稀缺，于是就业市场就出现了一种典型的金字塔结构：底层是大量的普通学校毕业生，中层是少数优质高校，顶层是极少数顶级名校。而越往上竞争越激烈，但回报也越大。看商业上的案例，中国早期互联网的创业者几乎清一色的来自清华北大。比如字节跳动的张一鸣，位于南开大学；腾讯的很多技术骨干都来自于清华；美团的王兴毕业于清华；拼多多的黄峥和DeepSeek的两湾峰都毕业于浙大。这些学校之所以能持续产出顶级创业者并不是偶然，因为顶级大学不仅提供知识，更提供资源网络。你在大学里认识的同学、老师，还有校友，未来可能就是你的合作伙伴、投资人甚至客户，这就是所谓的校友网络。美国硅谷、斯坦福大学几乎是创业者的摇篮，硅谷创始人、YouTube创始人、英伟达的创始人，都和斯坦福有着深厚的联系。所以，学校本身就像一个资源生态，名校的真正价值，不只是那张毕业证，而是背后的认知圈层、资源网络和社会属性。

6. 名校的局限性与长期竞争力

当然，说到这里，必须提到一个误区，名校虽然很重要，但名校绝对不是成功的唯一途径。如果一个人只是考上了名校，没有持续学习的能力，那优势就会很快被消耗掉。现实中，也有很多普通大学毕业的人通过创业、投资、技术实现了逆袭翻身。比如很多的互联网创业者，并不是传统的名校背景。对名校的本质其实是起点优势，它能让你的人生在前期跑得更快，但并不保证你最后一定跑得最远。真正决定一个人长期上限的还是认知能力、执行力和长期的学习能力。不过，我们也必须要承认，在信息高度复杂的现代社会，筛选机制一定会存在，而学历就是最简单、最粗暴，也是最有效的机制之一。于是我们就看到，普通学历越来越像基础门票，而名校更像是VIP通道。这就像机场安检，所有人都可以从经济舱排队，但有些人可以走头等舱、商务舱的快速通道。现在全球顶级大学的学费动辄一年几十万人民币，为什么还有这么多人挤破头去读？因为大家都知道，在未来高度竞争的社会中，顶级教育依然是最稳定的上升通道之一。其实，不仅是教育的规律，也是社会的规律，任何行业普通能力都会越来越拥挤，而顶级的能力永远稀缺。与其焦虑学历贬值，不如思考一个更重要的问题，你有没有站在一个稀缺的位置？如果学历越来越普及，未来真正值钱的东西是珍宝。评论区交流。
