1. 非典型瘦子的三大常见顾虑

很多天生比较瘦弱的同学，都觉得自己的先天条件太差了。虽然很想健身增肌，但根本不知道从何开始。答案是看，但是我觉得我自己只能算是个非典型瘦子。什么是非典型瘦子？我发了留言发现，他们觉得自己在这三方面问题特别大。第一类是体型不匀称，虽然大家的胳膊都很细，但是有的人肚子上有不少赘肉，有的人上半身瘦，但下半身粗壮，这种情况要不要先减减脂再去增肌？第二类是体能特别差，像俯卧撑和仰卧起坐这种简单的徒手动作一口气都做不了几个。朋友都说，我应该先把体能练好了，再去健身房应该没错吧。第三类是体态有问题，圆肩、驼背、高低肩。体态有问题，练出来的肌肉会不会是歪的，是不是应该先矫正好体态，再去健身房比较好呢？

2. 体型差异分析与增肌优先策略

非典型瘦子的问题其实都非常的典型，我们一个一个来解决，首先是体型的问题。你有没有觉得胖子好像胖的都千篇一律，而瘦子们都瘦得千奇百怪？为什么瘦子的体型能够如此的多样化？只要从肌肉和脂肪的层面分析一下，就很容易弄明白了。瘦子里比较常见的是干瘦型的身材，他们全身都很瘦，几乎没有一丝赘肉，肋骨也清晰可见。很明显，这种体型的肌肉量很低，体脂率也很低。另一种常见的是胖瘦型的身材。他们明明四肢很瘦，但又长了个小肚腩，一时间分不清自己是胖还是瘦。这种体型肌肉量很低，但是体脂率偏高。还有一种不太常见的是混合型身材，他们大多数臀腿都非常粗壮，用手掐一下还挺结实的，肌肉量还是蛮发达的，但上半身和普通瘦子没有什么区别，胳膊都非常的细，头轻脚重很不协调。为什么会出现这种奇怪的体型呢？有蛮多的朋友平时可能喜欢骑行登山这类运动，臀腿是充分锻炼到了。但是上半身一点都不练，长年累月就形成了这种体型。这种体型局部肌肉量很低，体脂率有高的也有低的。这三种体型大家属于哪一种？可以来发个弹幕集合一下。这三种不同类型的瘦子分别应该怎么练呢？其实不一定要分别练，你仔细观察就会发现他们都有一个共性，就是肌肉量不足，无论是全身不足还是局部不足，我们的第一步都应该先把肌肉量给堆上去，让整个人壮起来。无论是没有什么赘肉的精壮，还是圆滚滚的肥壮都没有关系。只要壮了，你就不再属于瘦子的范畴了。所以在不同体型的瘦子应该怎么练？这个问题上，答案很唯一。先整个练壮了再减脂或者做其他操作。这是对瘦子来说，效率最高的方法，直接去健身房练起来就行了。而增肌和减脂也未必不能同时进行，特别是在新手刚开始练的那几个月，也就是我们常说的新手红利期。由于身体刚接触新的刺激，肌肉量和体脂率都会逐渐恢复到正常的水平。这段时间里是很可能出现增肌减脂同时出效果的现象的，所以真的不要顾虑太多，就按照我的增重教程里的计划先练起来，效果自然就出来了。对于混合型的瘦子来说，可能会多一层顾虑。我只是上半身瘦，但是大腿已经足够粗了，而且是实打实的肌肉，再这么练下去，会不会上下失衡的更严重？我们思维活络点嘛，你觉得腿太粗了就少练点呗，把大部分的训练时间都留给上半身的肌群，每周就蹲一次腿稍微维持一下不就可以了。

3. 体能误区与力量训练的正向循环

接着是体能问题，先把体能练好，再去健身房举铁，这种说法其实是很迷惑的。请问你打算用什么样的方式来先把体能练好呢？大家可能都会有个共识，就是跑步能够有效的提升体能。是的，跑步确实是对体能有帮助的。但是你想想啊，原本你的俯卧撑都做不了几个，引体向上一个都拉不起来。然后你坚持每天慢跑，跑了一个月了，体能确实有改善了。那么这个时候你的俯卧撑就能够轻松做足了吗？你的引体向上就能够顺利的拉上去了吗？很大概率啊，和原来一样还是做不了几个，还是拉不起来。为什么会这样？因为体能不是一个笼统的词，而是有细分方向的：力量、速度、耐力、协调、柔韧、灵敏，这些都是体能的表现。你去跑步提升的是体能中的心肺耐力这一项，说细一点是摄氧能力和供血能力。做俯卧撑和引体向上要的是摄氧和供血能力吗？显然不是嘛，我们需要的是力量。力量从哪里来？主要就是从肌肉里来，肌肉又从哪里来？你去健身房练着练着，肌肉不就长起来了吗？这就是一个正向的内循环。去健身房举小铁，力量这一项体能就能够有效提升。提升了你就能够举起更大重量了。而在这个过程中肌肉和体能都会共同的进步，那我干嘛还要先去把体能练好呢？所以对于体能的问题，建议和体型那条一样，不要顾虑太多，就按照我增重教程里的计划，先练起来，体能自然就上去了。

4. 体态问题解析与行动建议

最后是体态问题，圆肩驼背、高低肩、肋骨外翻、异状肩胛、骨盆前倾等等等等。瘦子出现不良体态的概率确实比普通人要高得多。不良体态是怎么来的？第一，体态是骨骼问题，骨骼歪了、扭了、移位了，反正不在正确的位置上了，那么外在表现出来就是我们不正确的体态了。第二，肌肉是附着在骨骼上的，肌肉的情况对骨骼的位置会有影响。第三，瘦子的肌肉量比普通人要低得多，没有足够的肌肉力量，就不容易将骨骼维持在正确的位置上。这就是为什么我们瘦子总会有一些奇奇怪怪的体态问题。不良体态对我们增肌增重有影响吗？当然是有的。有时候我们觉得肌肉练的不太对称，例如胸肌一边大一边小，可能不是你练的有问题，而是你的脊柱有点侧弯才导致大小胸的。因为骨骼是肌肉的地基，地基都歪了，无论怎么练，上面的肌肉肯定也是歪的嘛。听起来有点严重啊，那需不需要先把体态矫正好，再开始增肌训练呢？如果只是轻微的体态问题的话，其实是没有必要的。因为体态矫正是一项周期极长、见效极慢的大工程。等你把体态矫正好了，至少三五年就过去了，我保证你早就不想练了。而我们的身体在生长发育的过程中，是不可能保持完美的状态的，多多少少都会有点问题。对我自己胸椎段就有着轻微的脊柱侧弯，导致非常明显的高低肩。在健身前还有着严重的圆肩驼背，那我是怎么对待自身的体态问题呢？当时我根本就没管，直接练。这么多年练下来，伴随着肌肉的增长，除了体态已经在不知不觉中明显要比以前要好很多了。这是怎么改善的？伴随着我肌肉量的恢复，肌肉有足够的力量将骨骼维持在正确的位置上了，那么很多轻微的体态情况就自然消失了呗。而严重一点的，例如高低肩，虽然没有当年严重了，但其实我现在还是有一点。以前总是有人问，为什么我拍视频要像这样侧着伸直站？因为我有高低肩啊，你看正着站就很明显了呀，侧着站不就看不出来了嘛。那么这个体态我为什么不去矫正呢？因为引发我高低肩的根源，是我的胸椎段有着轻微的脊柱侧弯。这个可能就是我从小不良坐姿养成的，成年后早就定型了，不严重，还不到五度，但它确实就改不了了。所以无论我怎么练，两边的肌肉多少都是有点歪的，实在要矫正的话呢，也不是没办法。脊柱侧弯是可以做手术矫正的，但我觉得吧，我也犯不着花这么大的代价。我的选择是调整一下心态，接受自己左右不平衡的事实就可以了。没有什么事情是完美的嘛，反正肌肉量积累够了，身材已经比普通人要好很多了。所以对于体态的问题，建议和上面体型和体能的都一样，不要顾虑太多。就按照我增重教程里的计划，先练起来，或者一边训练增肌，一边进行适当的体态矫正练习都可以，反正身材自然会越来越好的。这里需要稍微补充一点啊，上面说了体态问题是比较轻微的，不太影响生活和运动的情况。如果你的体态问题已经非常严重了，例如超过十度的脊柱侧弯，严重的长短腿之类的。在医学诊断层面属于比较严重的骨骼类疾病问题了，那确实就不适合训练了。这种情况必须去医院咨询医生评估严重的程度和解决方案，把疾病解决了，再考虑训练。好了。总的来说，我们瘦子先天条件都好不到哪里去。但最大的问题不是条件差，而是想得太多，做得太少。既然行动起来，练起来，大部分问题都会自己消失掉的。
