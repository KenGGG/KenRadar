（二）核心内容

  1. 论文背景与方法概述 该论文来自EMNLP 2024，由一家小型资管公司的系统交易组撰写。核心目标是探索仅使用大模型通过新闻文本预测股价。研究分为两个模块：一是将文本转换为特征向量（Feature Vector），二是利用该向量预测股价涨跌。论文进行了大量A/B测试，对比了Encoder与Decoder模型、不同文本表示方法（Bottleneck与Aggregation）以及传统情感分析模型的效果。

  2. 实验设计与数据质疑 论文使用2003年至2019年的历史数据进行回测，涵盖北美、欧洲和新兴市场。视频指出数据存在严重缺陷：时间跨度老旧，未包含疫情后数据，且可能存在数据泄露（Data Leakage），即预训练数据中可能混入了2019年后的股价信息，导致结果虚高。此外，数据提供商隐藏细节，新兴市场定义模糊，样本量较少（每股票约两篇文章）。

  3. 模型表现对比结果 在北美市场，Decoder模型（特别是Llama和Mistral）整体表现略优于Encoder模型（如DeBERTa）。文本表示方面，Aggregation（平均所有Token向量）和Bottleneck（使用CLS Token）效果因模型而异，无绝对优劣。在Long/Short策略中，Llama做空表现较好，Mistral做多表现较好。传统情感分析模型（Sentiment/NERSIS）效果最差。

  4. 不同市场与策略的差异性 欧洲市场中，Mistral结合Aggregation表现最佳，Llama做空效果好，但整体收益低于北美。新兴市场数据表现混乱，部分模型做空亏损严重，显示策略高度依赖具体市场环境。视频总结认为，不存在在所有市场和策略下都最优的模型或表示方法，需具体问题具体分析，并根据资金量和策略类型进行针对性回测。
