（二）核心内容

  1. 个人背景与现状 主讲人自述为重庆人，父母为货车司机，童年为留守儿童，受偏瘦基因影响体重最高仅110斤。大专毕业后南下深圳，目前在卓叔淘宝店从事打包工作，日常体力消耗大。

  2. 长期犹豫未练的原因 虽卓叔与范老师多次邀请训练，但因仓库至健身馆通勤超一小时、下班后体力透支，加之家境、成绩、外貌均普通导致的自卑心理，以及担心在公众注视下失败丢脸，始终未能下定决心。

  3. 心态转变与决策契机 云南同行期间听闻卓叔分享健身初期心态：不设宏大目标，坚信只要开始行动，结果绝不会比原地踏步更差。该观点促使主讲人反思自身“想多做少”的生活模式，决定放下顾虑立即执行。

  4. 后续计划与录制初衷 即日起按卓叔计划执行训练与饮食，每1-2周更新记录供参考，每月进行体型对比。希望通过公开监督增强自律动力，并为同样偏瘦的观众树立信心，首期录制坦言紧张并呼吁持续关注。

1. 自我介绍与家庭背景

Hello，大家好，不知道大家还认不认得我，我就是卓叔视频里那个经常跟范老师对线的瘦子小哥。可能你们对我的印象除了出色的演技，就是我作为工具人的那个迷之微笑吧。今天录这个视频，是因为每次卓叔更新都有人问，哎，那工具人小哥咋还这么瘦啊？其实这背后是有原因的。抛开卓叔这边演员客串的因素，在生活里我自己就是一个再普通不过的小屌丝。我老家是重庆的，爸妈也是那种很普通的货车司机，小时候他们都在外地挣钱。我作为留守儿童，在这家亲戚住段时间，在那家亲戚住段时间，没什么人管，也没好好吃过饭。再加上我爸妈都是偏瘦的基因，所以从小到大我就没怎么胖过，体重最重的时候也就一百一十斤吧。

2. 工作现状与训练犹豫的原因

大专毕业以后，我南下深圳搬砖，换了几份工作，现在是在卓叔的淘宝店里面做打包的工作，也算是机缘巧合。今年卓叔要拍瘦子增重的视频，需要一个瘦子模特，然后就找到我了，就一直拍到了现在。当然这并不是说卓叔不让我练，恰恰相反。从一开始拍视频的时候，卓叔和范老师就一直劝我说可以带我练起来，但是我一直没下定决心。一是因为我工作的仓库离卓叔这边的馆子太远了，从龙华到南山要一个多小时。而我本身的工作里面其实有大量的体力劳动，要么是搬货，要么坐在那里打包一整天。每次下班其实都筋疲力尽，感觉浑身被掏空了一样，再坐这么远的公交过来，真的需要挺强的决心。然后第二个也是最主要的，就是对自己没什么信心。因为我觉得自己从小到大真的就是一个普通的、再普通不过的男生，家境普通，成绩普通，学校普通，长相也普通，一直有一点自卑。虽然我知道很多人跟着卓叔都练壮了，但是放到自己身上还是会不自觉的想，哎，我真的可以吗？再加上大家这么多双眼睛盯着，那压力就更大了，万一自己不行，那不是很丢人，这反而就更不容易开始了。

3. 云南之行带来的心态转变

但是今天我想借这个视频跟大家正式的说一声，从今天起我要开始增重了。为什么下定决心了呢？其实因为前段时间和卓叔他们去云南玩儿，有天晚上听到卓叔他们聊起刚开始健身时的心态。卓叔说，其实当时他根本没有想过自己之后身材会变得多好啊，没有多么大的目标。但是他相信一点，就是只要开始行动了，无论最后的结果如何，至少都不会是现在这个样子。那这段话对我的触动还是挺大的。好像过去这些年，不管在工作上还是生活上，我都是那种想了很多，但做的很少的人，这样反而就在不断的原地踏步。那在健身这件事情上也是一样的。嗯，与其总想着我能不能行啊，倒不如什么都不想，先练起来再说吧。就像卓叔说的嘛，无论成败，至少我们都不会是原来的样子，对不对？干就完了。

4. 增重计划与录制初衷

所以从今天开始，我就会按卓叔的计划练起来、吃起来。计划是每过一到两周，我就会在这里更新一次，来记录这周自己的训练和饮食情况，希望给大家一个实际的参考。每个月呢我也会再做一次对比总结，看看体重和体型上有什么变化。我觉得用这种全程记录的方式，一方面是有你们在监督，会让我有更多的动力，不要偷懒；另一方面也是想给大家，特别是那些和我一样瘦的兄弟们，多一些信心。如果我能从一个这么瘦、这么细的状态下，还能练出不错的身材，那么你们一定也可以的。第一次这样子录视频还是非常紧张的，希望大家可以持续关注。我也关注卓叔，加油，我们一起变强。
