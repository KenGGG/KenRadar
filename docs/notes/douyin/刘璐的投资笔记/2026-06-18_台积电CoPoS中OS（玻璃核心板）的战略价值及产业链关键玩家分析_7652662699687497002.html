台积电CoPoS中OS（玻璃核心板）的战略价值及产业链关键玩家分析

一、内容简述

（一）一句话结论

一句话结论 文章指出，在AI芯片封装技术CoPoS中，决定未来能否量产和稳定工作的关键并非仅在于COP（制造效率），更在于OS（玻璃核心板）。玻璃核心板作为“地基”，解决了超大尺寸AI芯片的翘曲、供电不稳和良率问题，其核心价值在于提升电源完整性（PI）而非单纯降低成本。产业链中，伊比等（EBD）作为高端ABF载板龙头，将受益于从传统ABF向玻璃核心板升级的过程；群创作为。

（二）核心内容

  1. CoPoS技术核心：从COP到OS的层级跃升 台积电CoPoS技术中，COP主要解决生产效率和切割成本问题，属于‘怎么做’的层面；而OS（Glass Core Substrate，玻璃核心板）解决的是‘能不能做出来’及稳定性问题，属于更高层级。没有OS，超大尺寸AI芯片难以实现稳定封装。

  2. 玻璃核心板的功能定位：AI芯片的‘地基’ 类比盖楼，GPU/HBM/光互联是上层建筑，玻璃核心板则是地基。其作用包括提供稳定性、平整度、机械强度及电源完整性（PI）。通过TGV（玻璃通孔）技术缩短电源路径，降低电阻和电感，从而提升供电稳定性，释放芯片功率空间，支持更高频率和更强算力。

  3. 产业链关键角色：伊比等（EBD）与群创的协同 伊比等是全球高端ABF载板核心玩家，传统ABF面临大尺寸封装极限，需升级为‘玻璃+ABF Build-up’结构。伊比等凭借强载板工艺能力，控制翘曲并解决热膨胀不一致问题。群创作为面板厂，掌握大尺寸玻璃加工切割强项。三者（台积电、伊比等、群创）组合构成CoPoS落地基础。

  4. 投资价值逻辑：从成本项转向价值项 玻璃核心板虽单价高于传统ABF，但在AI芯片总成本中占比不高。其核心价值在于提高良率、减少因封装失败导致的超高价值芯片报废，并提升芯片性能。客户愿意为性能提升和良率保障付费，因此该环节具备强议价能力和投资吸引力。

二、分段原文

以下内容保持博主原意和论述顺序，仅修正明显错别字、ASR 识别错误、标点与断句。

1. CoPoS技术核心：COP与OS的区别

台积电CoPoS里面啊，真正能决定未来AI能不能做出来，能不能稳定工作，能不能量产的关键可能不是CoPoS的COP，而是后面两个OS。什么是OS呢？就是Glass Core Substrate（玻璃核心板）。这句话也比较关键，因为过去市场提到CoPoS，很多人第一反应是台积电要搞板芯，面积会更切，切割效率也会更高，成本更低，所以呢大家都会把聚焦点放在COP上面。但是这一次呢，台积电泄出来这个PPT真正想告诉市场的是，COP只是解决怎么更高效生产的问题，而后面的OS解决的是这个东西到底能不能做出来的问题。这两者呢其实不是一个级别的，没有COP芯片呢可能只是贵一点，效率低一点，切割没有那么经济；但是没有后面两个OS的话，也就是没有玻璃核心载板的话，未来超大尺寸的AI芯片可能连稳定的封装都很难。

2. 玻璃核心板的作用：AI芯片的‘地基’

因为AI芯片呢现在已经不是过去那种单颗芯片的逻辑了，它要把GPU、HBM、高速互联、供电网络全都塞在一个超大的封装里面。封装面积越大问题就越多，翘曲啊、变形、供电不稳、良率下降、可靠性下降。我们可以把它简单理解成我们盖一座楼：GPU呢类似于像楼上的豪宅，HBM呢是楼里面的核心设备，CPU光互联是交通系统。但是玻璃核心载板是什么呢？它是地基，如果地基不稳的话，上面装修再豪华其实也没有用。这就是为什么这次台积电会把伊比等还有群创拉进来，意义呢其实非常重大。

3. 伊比等（EBD）的角色：从ABF到玻璃核心板的升级

伊比等是谁呢？它是全球高端的ABF载板最核心的玩家之一。过去英伟达MDAI芯片要做高端的封装，那么离不开ABF载板，而伊比等的话长期是处在这个产业链最核心的地位。现在的问题呢是传统的ABF载板面对未来更大尺寸的AI封装开始遇到极限问题了，不是ABF不重要，而是单靠这个ABF呢它是不够的。所以新的结构会变成什么样子呢？中间会有一层玻璃核心，两边呢再叠ABF的Build-up层。也就是说玻璃这块它不是取代说ABF，而是升级ABF的地基。玻璃负责的是稳定性、平整度，还有机械强度以及电源的完整性。而ABF呢负责的是这个泄露，还有增层。所以这不是ABF被淘汰，而是高端的ABF载板呢进入了下一代形态里面。这也就是为什么伊比等会更关键呢？因为玻璃核心载板，它不是简单的拿一块玻璃切一切就能用，它需要和ABF增层相结合，要控制它的翘曲，还要解决材料热膨胀不一致的这些问题。另外还要同时保证超大尺寸的这个封装它的良率。所以这里面都需要非常强的这个载板工艺能力。而伊比等是传统高端封装载板里面最强的一批玩家。

4. 群创的角色：大尺寸玻璃加工能力

但是伊比等它也不是独角戏，这是另外一个关键的角色就要出来了——群创。为什么一个面板厂突然会变得重要呢？因为玻璃核心载板，说到底它还是大尺寸的玻璃呢加工切割处理，本来这个就是面板厂的强项。所以呢台积电这一次的组合很有意思：台积电呢掌握了先进封装路线，伊比等掌握了高端的ABF载板还有封装载板的能力，群创掌握的是大尺寸的玻璃加工能力。这三者组合起来才是CoPoS里面OS能够真正落地的基础。

5. 技术细节：TGV与电源完整性（PI）

更重要的是，这次玻璃核心载板的价值，它不只是说更平一点、更硬一点这么简单，而是它能改善PI，也就是Power Integrity（电源完整性）。这个词儿听起来确实有点技术性，但是其实比较好理解。当AI芯片越大的时候，用电会越猛。你要让GPU、HBM还有互联模块同时能够高速运行的话，电必须要供得稳定。如果说供电不稳，芯片这块就跑不起，高频性能呢就上不去，也会影响到它的良率。玻璃核心载板里面有一个关键的技术叫TGV（玻璃通孔），它可以让这个电源通过更短的垂直路径传出。如果路径短了，电阻就降低了，电感降低，供电呢就能更稳定，芯片的功率空间呢这就释放出来了。这对客户而言意味着什么呢？意味着可以塞更多的晶体管，可以把频率推的更高，可以让这个AI芯片的算力更强，这才是客户这块块愿意付费的地方。

6. 商业逻辑：价值项而非成本项

客户呢不会因为台积电生产效率提高，就会贵几倍，因为那个代工厂己己的事儿。但是如果玻璃核心载板能够让英伟达的芯片性能更强，功耗更稳，良率更高，那客户一定愿意买单。所以呢玻璃核心载板它不是简单的成本项，而是价值项。表面上看，它比传统的ABF载板要贵好几倍，但是问题是基本在整个AI芯片成本的占比并不高。真正贵的是什么？是先进封装。如果失败的话，这个是良率损失，是一颗超高价值的AI芯片，因为封装问题而报废。如果说玻璃核心载板能够减少翘曲提高良率，能够改善供电的稳定性，那就算单价如果再贵的话，客户也是愿意买单的。这就是这条线最核心的投资逻辑所在。

7. 投资趋势与结论

过去呢我们看AI，第一阶段看的是CPU，第二阶段看的是HBM，第三阶段看光模块、PCB。但是越往后走的话，市场又发现真正卡住AI芯片继续变大的不只是算力本身，而是封装地基。所以玻璃核心载板这条线呢，它不是简单的炒玻璃，也不是说单炒个材料，而是站炒AI芯片继续放大的必要条件。未来AI芯片封装尺寸越来越大，CoPoS逐渐放大的话，CoPoS逐步走向量产，那么玻璃核心载板的重要性就会越发凸显出来。而在这条链条里面，伊比等的意义呢也会被重新认识。它不是一个普通的载板公司，而是站在高端ABF向玻璃核心载板升级过程里面的关键玩家。过去呢它吃的是AI芯片ABF载板的红利，未来如果说玻璃核心载板路线跑通的话，他吃的可能是下一代AI封装地基升级的红利，这是一个关键的变化点。所以这次台积电PPT最重要的信号呢，它不是说玻璃基板来了这么简单，而是在告诉市场，AI芯片的竞争已经从GPU本身延伸到了封装地基，谁能让未来AI芯片更稳定的做出来，所以就掌握了下一个阶段算力扩张的门票。总而言之，这就是为什么我们认为玻璃核心载板、伊比等，还有群创、ABF、先进封装这条线，接下来这是我们必须要重点关注跟踪的一条线。
