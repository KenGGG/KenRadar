## 一、内容简述

### （一）一句话结论

> [!summary]
> 本文介绍了 Claude Code 的两层配置架构（系统层级与项目层级），共涉及七个核心文件。通过合理配置，可将 Claude Code 打造为具备全局工作流约束和项目专属记忆的独立 AI Agent，实现‘配一次，管所有’的高效开发体验，避免重复交代背景与规则。

### （二）核心内容

1. **配置架构概览**
   Claude Code 配置分为系统层级（全局生效）和项目层级（单项目独立）。系统层级包含3个文件，对所有项目共享；项目层级包含4个文件，仅在当前项目生效。

2. **系统层级配置详解**
   系统层级包含 .claude.md（定义身份与工作流）、.claude/settings.json（权限钩子与环境变量）以及 .claude/rules.md（代码规范与安全规则）。其中 settings.json 可配置工具权限 bypass、环境变量等过渡系统。

3. **项目层级配置详解**
   项目层级包含 .md（项目背景与工作方式）、memory.md（项目记忆，系统层级无此功能）、commands（命令集）及 settings（项目专属设置）。该层级让 AI 记住特定项目的上下文、风格及历史题材。

4. **应用场景与优势**
   通过配置，Claude Code 可针对不同项目（如亚马逊选品、短视频创作）自动加载专属规则与记忆。例如，在短视频项目中，AI 能自动继承之前的题材与风格，无需每次从头介绍，显著提升效率。
