1. 引言与核心观点

我最近在看分钟数据和盘口数据的时候，发现一个很反直觉的现象。很多股票如果当天要涨，真正最有效的那段上涨，往往不是下午走出来的，也不是尾盘突然拉出来的，而是开盘最前面几分钟。有些票九点三十到九点三十五，这五分钟已经完成了全天大部分有效涨幅，后面几个小时看起来还在交易，但本质上可能只是震荡回踩，换手确认，甚至是回落。所以今天这期我不想讲普通的盘口技巧，比如什么高开高走，低开高走，放量上涨。这些太表面了，我想从市场微观结构的角度讲清楚一个问题，为什么开盘五分钟这么重要？它到底在反映什么，以及我们怎么用数据去验证它。先说结论，开盘五分钟不是普通的五分钟，是三个东西同时发生的地方：第一，隔夜信息集中进入价格；第二，订单簿重新建立流动性；第三，主动买卖盘决定第一轮价格冲击。这三个东西叠加在一起，就导致开盘几分钟的信息密度远远高于日内大部分时间。很多人看开盘只看涨跌幅，但专业一点看开盘其实就是一个价格发现实验，英文叫Price Discovery。价格发现是什么？不是说价格涨了，就是发现了，而是市场把新的信息通过订单成交和报价压缩竞价。

2. 隔夜信息清算与集合竞价机制

A股下午三点收盘以后，交易停止了，但信息没有停止，公告还在发，外盘还在动，行业信息还在发酵，资金还在重新评估第二天的计划。可是A股不能连续交易，所以这些信息最后都会堆到第二天早上，先进入集合竞价，再进入九点半之后的连续竞价。所以开盘不是一天的普通开始，而是隔夜信息的一次集中清算。这就是为什么很多票开盘五分钟波动特别大，你看到的不是随机波动，而是十几个小时累积的信息被压缩在几分钟里，重新定价。但是这里有一个很关键的点，集合竞价给出的只是第一个价格，连续竞价才是真正的压力测试。什么意思？集合竞价确定了一个开盘价，但这个价格到底有没有人认可？要到九点半之后才知道。高开不代表强，低开也不代表真弱。真正重要的是，开盘价出来之后，连续竞价里的主动买盘和主动卖盘谁更急？

3. 订单不平衡与价格冲击分析

这就进入第一个核心指标，订单不平衡，英文叫Order Imbalance。最简单的公式是订单不平衡，等于主动买入金额减去主动卖出金额。如果要标准化，可以再除以总成交金额，也就是（主动买入金额 - 主动卖出金额）/（主动买入金额 + 主动卖出金额）。这个数越接近一，说明买方越主动，越近负一，说明卖方越主动。但这里最重要的是，订单不平衡，不能单独看，一定要和价格变化一起看。因为同样是主动买入很强，含义可能完全不同。第一种情况：主动买入很强，价格也快速上涨。这说明买盘不只是多，而且真的打穿了卖方流动性，这叫有效价格冲击。第二种情况：主动买入很强，但价格涨不动。这说明上方卖盘很厚，买的人确实多，但卖的人也很坚决，这就不是强势，就像买盘被吸收。第三种情况：主动卖出很强，价格却跌不动。这说明下方承接非常强，买盘打出来了，但价格没有被打穿，这叫卖盘被吸收。所以开盘五分钟的核心不是看买多还是卖多，而是看订单流有没有形成价格冲击，价格冲击能不能持续，持续以后有没有被市场吸收。这里就要讲第二个微观结构概念，Price Impact，价格冲击。最简单的公式是价格冲击，等于收益率除以有方向的成交金额。比如开盘五分钟涨了百分之二，主动买入金额是五千万，那么五分钟的价格冲击就是百分之二除以五千万。它的含义是每一块钱净流入到底推动了多少价格。很多人以为价格冲击越大越好，其实不一定。如果价格冲击特别大，可能说明买盘很强，但也可能说明盘口很薄，一点资金就被价格打飞了。这种上涨看起来很猛，但不一定稳。真正高质量的上涨，不是单纯冲击大，而是三件事同时成立：第一，主动买盘为正；第二，价格稳步上行；第三，冲完以后回撤很浅。这说明买方不是靠一瞬间扫单把价格打上去，而是有持续承接。

4. 流动性韧性与买卖价差

这就进入第三个概念，Liquidity Resilience，流动性韧性。什么叫流动性韧性？就是市场受到冲击之后，能不能很快恢复稳定。举一个例子，一只股票开盘五分钟涨了百分之三，如果后面马上回撤百分之二点五，甚至跌回开盘价附近，这比百分之三的上涨很可能只是一次流动性冲击，它不是稳定趋势。但如果它开盘五分钟，涨了百分之三，后面只回撤百分之零点五，然后一直在高位横住。这说明市场已经接受了这个新价格，这叫价格被确认。所以你会发现，开盘五分钟，真正重要的不是涨幅，而是涨幅之后的韧性。我建议你用一个指标：冲击后回撤率。公式是（九点三十五之后到十点之间的最低价 / 九点三十五价格）- 1。如果这个回撤率很小，说明承接强。如果这个回撤率很大，说明第一波冲击没有被确认，这比单纯看开盘涨幅有用得多。接下来讲第四个概念，Bid-Ask Spread，买卖价差。买卖价差就是卖一价减买一价。更标准一点，用相对价差：（卖一价 - 买一价）/ 买一卖一中间价。这个指标看的是交易成本，也看的是市场不确定性。开盘一段买卖价差通常更容易变宽。为什么？因为这时候信息不对称最强，有人可能知道消息，有人可能只是被动交易，有人可能是被迫调仓。对于挂限价单提供流动性的人来说，最怕的是什么？最怕自己卖给了比自己更懂的人，这叫逆向选择，Adverse Selection。比如你挂了一个卖单，结果开盘后有人非常坚决的把你的卖单吃掉。你会想他为什么这么急着买，是不是有什么我不知道的信息？于是你要么撤单，要么把卖价挂高，这样一来，盘口流动性就变薄，价差就会变宽，价格冲击就会变大。所以，开盘五分钟的涨跌不只是资金多空的问题，它还包含了流动性提供者的恐惧。如果流动性提供者害怕被知情交易者打穿，它就会撤单，它一撤单，价格就更容易跳。再就是开盘波动大的微观结构原因。

5. 订单簿深度与微观价格

再讲第五个概念，Limit Order Book，订单簿。很多人看盘口只看买一卖一，但真正的订单簿要看深度，比如买一到买五有多大量，卖一到卖五有多大量。挂单是越来越厚还是越来越薄？价格上涨的时候，真正强的结构不是买一突然变大，而是买方深度持续上移。也就是说，买盘不只是在低位等，而是愿意主动提高价格。这里可以用一个指标，Micro Price，微观价格。公式是（卖一价 * 买一量 + 买一价 * 卖一量）/（买一量 + 卖一量）。这个公式听起来有多少，但也逻辑很简单。如果买一量特别大，卖一量特别小，说明买方压力更强，微观结构会更靠近卖溢价。如果卖一量特别大，买一量特别小，说明卖方压力更强，微观结构会更靠近买一层。普通中间价，只看价格，不看微观结构，还把盘口数量考虑进来了。所以开盘五分钟里，你不能只看成交价，还要看微观结构是不是领先成交价上移。如果成交价还没怎么动，但微观价格持续上移，说明买方压力正在累积。如果成交价在涨，但微观价格不跟，说明上涨可能只是成交冲击，不一定有盘口支撑。

6. 开盘涨幅捕获率与分类验证

为什么比普通K线深一层？现在回到我开头说的那个现象，为什么很多股票开盘五分钟已经涨完了？因为很多股票当天的主要信息，其实在开盘阶段就已经完成了价格发现，后面没有新的信息，只是交易摩擦。这时如果你再追，买到的不是信息溢价，买到的是价格发现之后的残余波动。我建议用一个指标来验证：Open Five Capture Ratio，开盘五分钟涨幅捕获率。公式是开盘五分钟收益率除以全天开盘到收盘收益率，也就是 R(9:30-9:35) / R(9:30-收盘)。如果这个比例很高，说明全天大部分有效涨幅已经发生在开盘五分钟。但是这个指标要注意处理两种情况：第一，如果全天收益接近零，这个比例会失真，要剔除。第二，如果大盘涨全天跌，这个比例不能简单地理解为冲高回落。所以更科学的做法是把股票分成四类：第一类开盘涨，后面继续涨，这叫开盘信息延续。第二类开盘涨后面回落，这叫开盘过度反应。第三类开盘涨，后面继续跌，这叫弱势确认。第四类开盘跌后面反弹，这叫卖压吸收。你会发现真正有研究价值的不是开盘涨不涨，而是开盘价格发现之后，后续收益是延续还是反转。

7. 量化实验步骤与评分模型

这就可以转成一个非常清晰的量化实验。第一步，取全市场分钟数据。第二步，每天计算开盘五分钟收益。第三步，计算九点三十五到收盘的后续收益。第四步，把股票按开盘五分钟收益分成十组，看最强的一组，后续是继续强还是反而回落？第五步，在开盘最强的一组里面，再按订单不平衡分。如果高订单不平衡组后续更强，说明开盘涨幅背后有真正资金推动。如果低订单不平衡组后续更弱，说明开盘涨幅可能只是跳空或薄盘口冲击。第六步，再加一个流动性的后续指标，即开盘冲高之后的回撤。如果开盘涨幅高、订单不平衡强、回撤小，这才是高质量开盘。如果开盘涨幅高，但订单不平衡不强，回撤大，这就是第一阶能开盘。所以这期视频最核心的结论是，开盘五分钟不是拿来捂脑子的。它是拿来判断价格发现质量的。普通人看的是涨了多少，专业一点看的是为什么涨，更专业看的是涨幅是由信息推动、订单流推动还是流动性薄导致的顺势冲击。这三种涨完全不是一个东西。第一种信息推动特点是开盘后订单流持续，价格稳步上行，回撤小。第二种订单流推动特点是主动买入明显占优，价格被连续推进，但后面要看是否有承接。第三种流动性冲击特点是成交不一定很大，但价格跳的很快，后面如果没有继续买盘，很容易回落。这三类如果不区分，你就会把假强当真强。最后，我给这套方法一个完整的评分模型叫Open Five Micro Structure Score，开盘五分钟微观结构分数。它由五部分组成：第一，开盘五分钟收益，代表价格方向。第二，订单不平衡，代表主动买卖压力。第三，价格冲击，代表资金推动价格的效率。第四，买卖价差变化，代表流动性成本有没有下降？第五，冲击后回撤，代表价格有没有被市场确认？Open Five Score = 开盘收益的标准化值 + 订单不平衡的标准化值 + 流动性改善的标准化值 - 冲击后回撤的标准化值 - 异常高价格冲击的惩罚项。为什么要惩罚异常高价格冲击？因为价格冲击太高，可能不是资金强，而是盘口薄。真正强的股票，不是轻轻一推就飞，而是大量资金进去之后，价格能稳稳抬高，而且不轻易掉下来。这叫有深度的强，不是没深度的冲。

8. 总结与研究方向建议

所以以后你看开盘不要只问它涨了吗？你要问：第一，谁在主动成交？第二，盘口深度有没有跟上？第三，买卖价差有没有收窄？第四，价格冲击是持续的还是瞬时的？第五，冲完之后有没有回撤？第六，九点三十五之后的收益是延续还是反转？这些问题才是市场微观结构真正关心的东西。这也是为什么我说很多股票一天的涨幅在开盘五分钟已经走完了。因为开盘阶段完成的是价格发现，后面阶段完成的很多时候只是流动性再分配。如果价格发现已经完成，你再追进去，赚的不是信息差，而是在赌后面还有没有新的订单流继续推，这两件事的难度完全不同。这期最后给做量化的人一个研究方向，你可以做三个检验：第一个检验开盘五分钟涨幅贡献率，看全市场股票里有多少比例的全天收益发生在九点三十到九点三十五。第二个检验开盘涨幅延续性，看Open Five Return和九点三十五到收盘收益期间是正相关还是负相关。如果正相关，说明开盘有日内动量。如果负相关，说明开盘存在过度反应。第三个检验订单流质量过滤，只保留那些开盘涨幅高、订单不平衡强、价差收窄、回撤小的股票，看看他们的后续收益是否显著好于单纯开盘涨幅高的股票。如果结果成立，就说明开盘涨幅不是Alpha，开盘涨幅背后的微观结构质量才是Alpha。市场最真实的态度，不是开盘价本身，而是开盘价出来以后，订单簿如何反应？价格能不能推进，流动性能不能补上？卖压有没有被吸收？冲击以后，有没有回撤？开盘五分钟，真正重要的地方就在这里，它不是一天的开始。它是市场对隔夜信息做出的第一轮定价实验。而一个会看市场的人，不应该只看实验结果，还要看这个结果是怎么被订单流做出来的。我是做量化的，西蒙，关注我，收看更多前沿量化研究技巧与知识。
