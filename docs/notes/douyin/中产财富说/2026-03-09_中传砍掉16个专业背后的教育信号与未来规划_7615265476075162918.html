1. 中传砍专业与AI替代趋势

一所全国顶级的传媒高校最近做了一个事儿，其实是在给普通家庭敲了警钟。中国传媒大学一口气砍掉了十六个专业，其中包括翻译、摄影、漫画。这些曾经非常火的方向，对很多普通家庭来说，背后其实释放了一个非常清晰的信号：未来十年，很多看似非常体面的专业，可能正在成为时代的弃子。对普通家庭来说，未来十年该如何规划，又该如何重新选择专业的方向呢？这件事如果你仔细读，会发现事情没有那么简单，真正的重点其实不是AI在抢饭碗，而是大学在重新定义什么才是值钱的能力。麦肯锡在2024年发布了一项报告，到2030年，全球将有30%的岗位将会被AI和自动化替代。但注意是，任务被替代，而不是职业和岗位被替代。简单说，就是重复性的工作会被机器接管，但真正复杂、需要判断、需要创造的部分反而会更值钱。传媒大学的这次调整其实就是这个逻辑，它不是简单地砍掉了专业，而是把传统专业重新组合。比如，摄影并入了影视摄影与制作，视觉设计并入了广告学院，还新增了智能影像艺术、智能视听工程、智能工程与创意设计这些新的方向。总结一句话就是，未来不缺会干活的人，缺的是指挥AI干活的人。

2. 案例分析：翻译与摄影的职业升级

举个简单的例子，以前做翻译需要大量的人力，一个人一天只能翻译一到两万字。现在像大模型、翻译工具，几秒钟就能出结果。但问题是，机器翻译的准确率在普通文本中可以达到90%，但在法律、医学、金融这些专业的领域，错误率依然非常高。所以现在很多翻译公司的岗位正在发生变化，过去招聘的是翻译，现在招聘的是语言工程师或者本地化的项目经理。他们不再是逐字翻译，而是用AI生成初稿来进行校对和语言调整。换句话说，未来的翻译不是写字的人，而是判断的人。再看摄影，很多人觉得AI摄影会让摄影师失业，但其实恰恰相反。现在的商业摄影最缺的不是会按快门的人，而是会做视觉叙事的人。一个有意思的变化就是，机器在替代执行层，人类在向导演层升级，这才是这次中传调整专业的第一层逻辑。

3. 选专业误区与三大核心能力

但问题来了，这件事儿对普通家庭来说意味着什么呢？首先影响非常大，因为很多普通家庭在给孩子选专业的时候，逻辑通常是稳定、体面、听起来不错。十年前，很多家长会让孩子选择会计专业，因为觉得会计稳定，结果现在财务软件智能化，基础会计岗位大幅减少。二十年前，很多人学英语是因为外贸的火热，现在AI的翻译越来越强，纯语言能力的价值也在下降。不仅观察过去二十年的专业变化，会发现一个非常残酷的规律：越是标准化的技能，越容易被技术替代。比如流水线式的设计、基础翻译、简单编程技术、财务甚至部分的法律文书工作。这些岗位有一个共同的特点，流程清晰，规则固定，可以拆解成步骤。人工智能最擅长干什么呢？就是按照规则执行任务，这就像工业时代替代劳动一样，现在AI替代的是标准的脑力劳动。那未来什么能力最值钱呢？答案很简单，只有三种能力在未来是升值的：第一种能力，是系统思考的能力，也就是能把复杂问题拆解。比如一个品牌广告，AI可以生成一百个方案，但哪个方案最符合品牌的战略、哪个方案最适合市场，这种判断必须靠人。第二种能力是跨学科的整合能力，现在很多赚钱的岗位几乎都是跨界的，比如技术加艺术、金融加科技、医学加AI。中传新增的专业，其实也是这个逻辑，把艺术和工程进行结合。第三种能力是人性的理解能力，这一点很多人都会忽视，但却是最核心的。因为商业的本质就是理解人性，无论是广告内容创作还是产品设计，甚至都是洞察人性。AI虽然可以模仿风格，但很难创造真正有灵魂的东西，这也是为什么很多顶级创作者的价值越来越高。比如全球最赚钱的创作者之一YouTube的MrBeast，他的团队已经大量使用AI做剪辑、字幕、做数据分析，但频道的核心创意仍然来自于人类。机器负责效率，而人负责创意。

4. 就业压力与未来选专业策略

所以你会发现一个有意思的趋势：技术越先进，真正顶级的人才反而越稀缺。对普通家庭来说，还有一个更现实的问题，未来大学专业的风险差距会越来越大。过去选择专业，顶多是工资少一点，未来选错专业可能直接找不到工作。教育部的数据，中国高校毕业生已经从2010年的630万上升到2025年的1200多万，毕业生数量几乎翻倍，但岗位结构已经发生了巨大的变化。简单说就是岗位的数量没有减少，但岗位的能力门槛在提高。这也是为什么很多高校都在做专业的整合，不仅是中传，比如清华大学近几年大幅扩展人工智能和交叉学科的项目，美国的斯坦福和MIT也在大量增加AI加上各种行业的专业。未来最稀缺的人才不是单一技能的人，而是复合型能力的人。普通家庭的孩子到底该怎么选专业呢？其实有一个非常简单的标准：第一，看这个专业是不是高度标准化的，如果是，那未来被AI替代的概率就会非常高。第二，看这个专业是不是工具型专业，如果只是学工具，而不是学方法论，那风险依然很大。第三，看这个行业有没有跨界空间，但真正有前景的专业，大概率都在交叉领域，比如AI加医疗、数据加金融。过去那种选一个稳定专业，然后干一辈子的路径正在慢慢消失。未来更像是一个不断升级能力的过程，你可能大学学的是一个专业，但工作十年后，你的核心能力可能完全不一样。很多家长最担心孩子输在起跑线，但真正拉开差距的从来不是起跑线，而是时代。工业时代体力最重要，信息时代知识最重要，AI时代判断力和创造力最重要。机器负责效率，人类负责方向。你觉得未来什么专业最有前景？评论区聊聊。
