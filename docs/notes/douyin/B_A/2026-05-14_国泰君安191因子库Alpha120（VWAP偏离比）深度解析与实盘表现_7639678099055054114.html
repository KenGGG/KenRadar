（一）一句话结论

一句话结论 本期视频详解了国泰君安191因子库中的Alpha120因子，即VWAP（成交量加权平均价）偏离比。该因子通过计算加权均价与收盘价的比值进行信号生成与标准化，核心逻辑在于捕捉尾盘因机构算法结束、散户恐慌或做市商行为导致的结构性定价偏差，预期次日发生均值回归。实盘数据显示，该因子在中证500成分股中五年累计收益超208%，夏普比率1.32。视频特别强调分母标准化。

（二）核心内容

  1. 因子定义与公式拆解 因子名为VWAP偏离比，源自国泰君安191因子库。公式由分子和分母组成：分子为Rank(加权均价 - 收盘价)，用于衡量尾盘折价程度，信号值越大表示尾盘被砸得越狠；分母为Rank(加权均价 + 收盘价)，近似于两倍股价，用于标准化处理，消除高价股与低价股之间的绝对价差影响，确保选出的是相对折价最大的股票而非绝对价格最低的。

  2. 经济学逻辑与驱动因素 尾盘折价股票次日易上涨的四个原因：1. 机构算法全天匀速买入推高均价，收盘时停止操作，不再压制价格；2. 散户恐慌性尾盘杀跌，次日情绪冷静后卖压消失；3. 做市商尾盘承接大量卖单，次日需回补库存形成买盘；4. 投资者损失厌恶导致被套者不会立即抛售，卖压减轻促使价格回归加权均价。这属于结构性定价偏差的修复过程。

  3. 实证数据与绩效分析 基于中证500成分股（425只）五年实测数据：IC均值约0.04，六年多空收益累计208%，夏普比率1.32。持仓期越长信号越强，日换手率36%带来约15BP的交易成本，年化扣除成本后仍有收益。实验表明若去除分母，IC将从0.046暴跌至0.003，证明分母是因子灵魂。

  4. 策略优化与组合建议 推荐将Alpha120（慢因子）与Alpha171（快因子）组合使用。单一因子虽有效但收益较薄，两者互补可将夏普比率提升至2.11。核心思想是‘慢即是快’，折价代表机会，因子组合才是归宿。

2. 公式分子：信号生成

我把公式拆成两个零件：分子和分母。一个管信号，一个管标准化，我们一个一个来。分子是加权均价减收盘价。加权均价是什么？就是今天所有成交的量价加权平均，是所有人的平均成本。如果加权均价等于十块，但收盘价只有九块五，说明什么？说明大部分人在十块买的，但尾盘被砸到了九块五。尾盘有人在狂卖，把价格压到了低于平均成本。加权均价减收盘价，就是在量化这件事儿，正值越大，尾盘折价越严重。因子赌的就是被砸的会反弹，被拉的会回落。外面还套了一个Rank，就是排名，从四百多只股票里选出尾盘最委屈的那批。

3. 公式分母：标准化与重要性

那分母呢？分母就是加权均价加收盘价，约等于两倍的股价，对它取Rank就是按价格高低排序。那为什么要除以它？我做了实验，把分母去掉，只用分子。结果IC从零点零四六暴跌到零点零零三，几乎没有选股能力了。一百块的股票差三块，五块的股票只差一毛五，不除的话，选出来的是最贵的，不是折价最多的。分母是灵魂，不是装饰。

4. 因子逻辑：为何尾盘折价次日涨

好，理解了公式，关键问题：为什么尾盘折价的股票第二天容易涨？四个原因。第一，机构算法全天匀速买入，推高均价，但收盘时已经买完了，不会再拖。第二，散户恐慌，尾盘杀跌，次日冷静后卖压消失，价格自然回来。第三，做市商尾盘接了大量卖单，次日要回补库存，形成买盘。第四，损失厌恶，被套的人不会马上卖，卖压减少，价格慢慢回到加权均价附近。这不是短期反转，是结构性定价偏差的修复过程。

5. 实盘数据验证

来看真实数据。中证500四百二十五只股票，五年实测IC均值挣零点零四，六年多空收益百分之二百零八，夏普一点三二。累计IC曲线五年稳步上行。最惊讶的是持仓期，一天IC零点零四六，二十天IC零点零五九，越持有越强。日换手百分之三十六，但十五个BP的成本年化吃掉百分之二十三，扣完还是赚的，但不太厚了。

6. 总结与组合建议

总结一下，公式一行：收盘低于加权均价的股票，明天更可能涨。分子管信号，分母管标准化，缺一不可。Alpha171是快因子，Alpha120是慢因子，两个组合夏普到二点一一。一快一慢，互补，慢即是快。折价即是机会，组合才是归宿。今天就到这里，关注不迷路，下期继续拆因子。
