Claude 三大产品深度解析：Project 系统、Cowork 与 Code

一、内容简述

（一）一句话结论

一句话结论 视频指出 Claude 并非单一产品，而是包含 Claude.ai、Claude Cowork 和 Claude Code 三个独立产品。重点介绍了 Claude.ai 的 Project 系统（跨对话记忆与知识库），区别于 ChatGPT 和 Gemini；Claude Cowork 作为桌面级助手，通过 50+ 连接器接管 Office 等软件；以及 C。

（二）核心内容

  1. Claude 产品矩阵概览
    Claude 包含三个产品：Claude.ai（网页版）、Claude Cowork（桌面级助理）和 Claude Code（编程 AI）。同一订阅即可使用全部三个产品。

  2. Claude.ai：Project 系统与私人助理
    核心功能是 Project 系统，允许用户设定专属指令（Custom Instructions）和上传知识库（Project Knowledge，支持 PDF/Word/Excel 等）。该功能实现跨对话记忆，目前 ChatGPT 和 Gemini 尚未具备。用户可将其打造为私人专属助理或项目经理，通过迭代指令和知识库提升专业性。

  3. Claude Cowork：桌面级全能打工人
    定位为桌面级 Agent，能接管电脑操作，包括读写文件夹、浏览器操作及跨 APP 多任务。拥有 50+ 官方连接器，覆盖 Office 套件（Word/Excel/PPT）、飞书、Notion、Google Drive 及 GitHub 等，实现自动化办公。

  4. Claude Code：全球第一编程 AI
    在 SWE-bench 榜单得分 80.8，位居全球第一，超越 ChatGPT 和 Gemini。获 Karpathy、Sam Altman 等顶级 AI 玩家验证。支持多 Agent、部署等功能，是开发者首选。用户可将 Claude.ai 的知识库逻辑迁移至 Code 使用。

1. 引言与产品概览

如果你只打开过 Claude AI 的网页，那我告诉你，你可能只用了它的三分之一。在同一个订阅中，Claude 是能用这三个产品的。今天花 8 分钟给大家讲清楚每个产品是什么，然后该用哪个。这是 Claude 的三个产品，左边 Claude AI，这个是网页版的，打开浏览器就能用。中间这个是 Claude Cowork，这是桌面级的助理，它是装在你电脑上的，能够接管你电脑干活的 Agent。最右边的是 Claude Code，它是装在电脑里的编程 AI。

2. Claude.ai 杀手级功能：Project 系统

它的杀手级是 Project 系统，你可以给它一套专属的指令，然后加一个资料库，然后 Claude 就能跨对话记住一切。然后目前呢 ChatGPT 跟 Gemini 都没有这个功能。它的应用场景就是我们日常使用的场景，只不过比普通的传统的 ChatGPT、Gemini 多了一个记忆系统，能成为你的私人的专属助理，而且能够逐渐的迭代。第一个是 Custom Instruction，这是制定的命令，就是你可以给这个 project 一套专属的命令，Claude 在所有的对话里都是遵守的。这就相当于你给 AI 配了一份岗位说明书，你不用像一个 ChatGPT 一样每次都去跟他聊一下背景。第二个呢，就是 Project Knowledge，它是整个项目的知识库，你可以上传 PDF 啊、Word 啊、CSV 啊、还有 Excel 啊、TXT 这些所有的文件。因为这个东西很耗 Token 的，平时也不需要去加载，所以你不能放在第一部分的 instruction 里面。你可以在 instruction 里面告诉他，你碰到某一条法律，那个法律之后，你去读这个 knowledge 里面的某个文档，这样就能非常精准的能解决你的一些问题，而不是说很多有幻觉的东西就会产生。所以这两个加起来，是一个跨对话持续的助手 AI 助手，而且它的 instruction 跟 knowledge 是可以升级迭代的。

3. Claude Cowork：桌面级接管与连接器生态

第二个是 Claude Cowork，定位一句话，就是把任务交给 AI 你去做别的，所以我给他起了个外号叫全球最强打工人。目前他有两个杀手级的能力。第一个能力是桌面级的接管，Claude AI 是对话级的，然后 Cowork 它是整台电脑都可以给他管，他能够直接读写你的文件夹，自动完成浏览器的操作，然后还包括跨 APP 的多任务，都是可以的。他是一个真正能在你电脑上动手干活的员工。第二个能力呢，就是它的 50 多个连接器的生态，这都是官方的连接器，还包括 Word、Excel、PPT、PDF 这些。然后第二排就是一些这个飞书、Notion、Google Drive 这些文件的系统跟沟通的系统。第三行就是 GitHub 这些编程用的。你用了 Cowork 就相当于你雇了一个能操作整台电脑，然后又能够懂你的打工人。

4. Claude Code：编程领域全球第一

第三个 Claude Code，它的地位是非常高的，它是全球第一的编程江湖地位。然后现在全世界顶级的 AI 玩家都在用它，编程跟 AI 玩家都在用它。包括前特斯拉的 AI 总监、OpenAI 的创始人，他之前是用 80% 的自己的编程，用 20% 的 AI，现在已经切换到 80% 的 AI，20% 的手动编程。我相信现在这是他可能一个多月前说的，现在可能又提升了。然后包括其他的玩家，Sam Altman、Junkin 这些全球 Vibe Coding 的头部玩家都在用它。它的 SWE 的评分，Claude 的真实评分是全球第一的，已经超越了 ChatGPT 还有 Gemini。我自己的使用，我现在已经开始把前面说的 Claude AI 的一些 project 直接转移到了 Claude Code 里面，因为它通过某种逻辑，它是能把知识库转移出来，然后 Claude Code 的逻辑也是能调用的。

5. 总结与下期预告

记住三件事：第一，Claude AI 它是一个跨对话记忆系统，你可以使用这个 Project 把 Claude 变成你的私人顾问或者项目经理，这个都是可以的。然后第二，Claude Cowork 是全球最强的打工人，能接管各种各样的 Word、Excel、PPT，以后它有 50 多个连接器。然后第三，Claude Code 它是编程 AI 的天花板，SWE 80.8 的分，大神的也是亲自验证的。然后下一期我会讲这个 15 分钟 Claude Code 的小白入门，欢迎大家关注我，我会持续更新 Claude 的深度实战内容，谢谢大家。
